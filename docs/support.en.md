# Getting help

- Help > User Guide explains first use, address format, macOS sign-in and automatic-mounting boundaries.
- Share details show status, configured/actual locations, next steps and diagnostics.
- Diagnostics in Settings can be previewed and exported explicitly. Check for information you do not want to share before sending; never send passwords.
- See `Known-Limitations.md` in the offline package for current limits.

# Feedback

The offline build has no online support portal. Use the channel you received the build from and include: macOS version, Automnt version, steps, on-screen messages and redacted diagnostics. Do not include passwords or unredacted full paths.
