Automnt 在本机管理 SMB 共享配置。本说明描述当前离线构建的实际行为，不构成法律意见。

# 数据

- 配置保存在本机固定配置目录；由程序创建，不手工写入。
- 登录信息由 macOS 与系统钥匙串处理；Automnt 不单独收集或保存密码，也不把密码写入配置或诊断。
- 无遥测、广告或第三方分析；诊断仅在你预览并主动导出时离开本机，不会自动上传。
- 日志保留 7 天且单文件上限 5 MB，可在诊断页清除。
- 连接共享时，你连接的服务器会处理连接请求；其隐私做法由该服务器决定。

# 你的选择

你可以在设置中关闭自动挂载、在 Finder 中弹出共享、移除已管理共享，或清除日志。拒绝系统后台/访问许可时，应用如实说明状态，不会创建第二份配置。
