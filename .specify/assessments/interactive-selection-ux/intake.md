# 概念重述与交互范式梳理

本次评估旨在全面解决 `automnt` 在 3.0.0 与 3.1.0 版本中发生的**终端交互退化**问题，彻底抛弃让使用者在终端中对照提示手动敲入数字编码或字母代号（如 `[1-2 / m / s / d]`、`[1-1 / a / m / d / u / q]`）的原始命令行模式，全面回归并超越 2.7.4 版本的高阶终端交互体验（TUI），将所有交互场景严格划分为五大清晰范式：

1. **单选即直接确定（Radio Navigation / Action Direct Confirm）**：
   - 表现形式：光标上下键（或 j/k）移动高亮焦点，单选菜单项（或带动作属性的菜单选项），按下 `Enter` 键即直接选定并触发执行。
   - 适用场景：
     - 初始化向导主操作：从候选主机列表、手动添加 `[m]`、跳过主机 `[s]`、完成配置 `[d]` 中移动光标直接 Enter 选择；
     - 日常管理主菜单：从各个主机顺位条目、新增主机、顺位调整、删除主机、更新策略、保存退出中光标移动直接 Enter 选择；
     - 主机下属共享管理操作：从追加共享、移除共享、批量切换状态、返回上级中直接 Enter 选择；
     - 调整顺位：选择目标顺位直接 Enter 完成；
     - 部署意愿与更新信道选择：直接高亮目标项 Enter 选择。

2. **空格单选再回车确认（Explicit Radio Selection）**：
   - 表现形式：单选状态显式展示为 `(o)` 与 `( )`，光标移动，按下 `Space` 切换选中单选框，按下 `Enter` 正式提交确认。
   - 适用场景：
     - 破坏性或高风险操作的二次确认：例如清空所有主机确认、删除指定主机确认，默认焦点置于“取消并返回”，需显式按 Space 切换到“确认删除”后回车确认；
     - 软件更新信道切换等持久化策略设置。

3. **空格多选再回车确认（Multi-Select Checkbox）**：
   - 表现形式：多选复选框明确展示为 `[x]` 与 `[ ]`，光标移动，按下 `Space` 切换单个勾选/反选，支持按下 `a` 键全选/全不选，按下 `Enter` 正式提交确认。
   - 适用场景：
     - 首次向导与日常管理中“下钻勾选主机从属共享”：列出该主机名下扫描到的全部 SMB 卷，Space 多选勾选，Enter 批量确认录入；
     - 日常管理中的“批量删除共享 / 批量删除主机”：复选框勾选要删除的条目，Enter 提交批量删除；
     - 日常管理中的“批量启用/禁用共享”：直观展现启用状态 `[x]`，Space 翻转状态，Enter 批量保存。

4. **务必支持 Esc 即时返回上级（Universal Esc Back & Cancel）**：
   - 表现形式：任何选单、多选框、确认弹窗及文本输入行，只要按下 `Esc` 键，立即安全退出当前环节，整行擦除，返回上一级菜单，绝对不保存半成品脏数据，不产生破坏性副作用。
   - 适用场景：
     - 首次向导的主机选择、别名输入、从属共享勾选；
     - 日常管理的主菜单、主机下属管理菜单、顺位调整、删除确认；
     - 手动录入 IP/域名、共享路径、别名等所有文本输入行。

5. **不得不保留手动输入的场景（Raw Text Input）**：
   - 表现形式：单行文本输入，支持退格擦除、默认值回车继承（如别名默认回车采用主机名）、Esc 整行清除并安全放弃。
   - 适用范围（严格限制在且仅在）：
     - 手动录入未挂载的新主机地址（IP 地址、局域网 mDNS 域名、公网域名）；
     - 为选定主机设置可选友好别名；
     - 手动录入未挂载的新 SMB 共享 URL；
     - 非标准端口与探活超时数值（如需自定义）。

# 来源与触发背景

- **提出人**：项目维护者
- **触发事件**：维护者在真实终端中运行 `automnt --init --reset` 与 `automnt --config` 时，发现界面要求用户输入代号（如 `[1-2 / m / s / d]`、`[1-1 / a / m / d / u / q]`），与 2.7.4 原有基于箭头光标与空格的交互体验相比发生了严重退化，操作繁琐且易输错。
- **当前时机**：Feature 002 已完成核心主机顺位模型与挂载点净化，底层已具备 Darwin 原生 termios 单字符捕获引擎；在此坚实底座之上全面重构 TUI 交互体验正当其时。
