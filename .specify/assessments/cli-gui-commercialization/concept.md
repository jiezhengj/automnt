# 产品不可削减的核心

GUI 配置完成后，在约定条件下自动挂载配置的共享，并在网络恢复或挂载丢失后自动处理；正常工作不要求用户先发现任务失败，再点击连接。缩小首版只能优先缩小辅助界面、可选功能和发行范围，不能删除自动挂载。保留实际边界：不能保证服务器离线或凭据无效时访问成功，也不承诺任意路径访问时即时连接或修复 Finder 侧边栏。

# 可选方向

## A：同项目自动挂载 GUI，通过 Mac App Store 买断发行

- **Sketch**：CLI 免费开源持续发布。用户从商店购买 GUI，完成共享配置与必要授权后，由产品持续提供自动挂载与恢复；界面服务于设置、说明自动化状态与异常处理。两种入口共同演进，核心修复共同受益。
- **Appetite**：medium（weeks）可作为首轮可行性投入预算的候选类别，尚未获批，不是工期估计；完整产品投入未知。可先只读核实规则，不自动开发验证程序。
- **Trade-offs**：最符合原始发行意向，商店提供获取与支付入口；平台权限和后台要求可能影响可实现的体验，需要证据确认。用户无需单独安装免费 CLI 才获得核心自动化，是候选产品目标，其技术与审核可行性未验证。
- **Rabbit holes**：为上架牺牲自动挂载、依赖用户逐次启动界面、未获确认的例外权限、两套业务规则、双后台冲突、承诺所有历史配置无差异共享。

## B：同项目自动挂载 GUI，直接签名公证分发并买断收费

- **Sketch**：继续提供同一自动挂载 GUI，但通过商店以外渠道获取与购买；CLI 仍免费开源。此选项仅在商店无法承载核心价值时供维护者选择，尚未获授权。
- **Appetite**：medium（weeks）作为可行性预算候选，完整产品及销售支持投入未知，不是估计。
- **Trade-offs**：可以另行评估更适合后台运行的发行边界；维护者需要承担安装信任、支付、更新和支持流程。直接分发不代表无需签名、权限或安全验证。
- **Rabbit holes**：为了收款引入复杂许可证系统，维护多个收费渠道和不同能力版本，重复建设更新与支持基础设施。

## C：暂缓收费 GUI，继续免费 CLI 自动挂载产品

- **Sketch**：继续维护现有自动化能力；在平台或商业证据不足时暂缓新增 GUI。需要人工连接的用户可继续选择现有工具，但不把 Finder 手动连接当作同等替代。
- **Appetite**：small（days）仅用于补充研究的候选预算；持续 CLI 维护另计。
- **Trade-offs**：控制第二产品投入；商店可获得性和收入推迟。保留已存在的自动挂载价值。
- **Rabbit holes**：不设结束条件的市场研究，或因延期而重新把核心问题缩减为界面操作便利性。

# 推荐理由与共同演进

推荐 A 进入规格定义：[研究](research.md)现已取得商店自动挂载收费先例、Apple 正式后台服务机制和应用内嵌 CLI 的文档，支持可信路线。A 是最小合格方案：首版聚焦 SMB，保留自动挂载、恢复与任务可使用的路径，缩小辅助界面；不与多协议成熟竞品全面对齐。更可靠与更易诊断是拟验证的差异价值，尚不能宣称胜过竞品。

建议将第一轮可行性验证预算设为 medium（weeks），例如最多两周，这是停止无边界投入的预算建议，须维护者后续批准，不是完成工期承诺。完整产品预算未知。在目标签名和沙盒环境中，只要出现无法合规解决的任务路径、逐次授权、后台运行、凭据或死卷恢复障碍，就停止商店路线并决定 B 或 C。第三方 Helper 先例不是免审许可，不默认外装不受限程序。不能用手动挂载器替代 A。

共同演进应按用户可见结果评估：相同条件下的自动挂载决策、恢复语义和安全边界一致，共同修复惠及两个入口。安装、授权、后台注册和更新可以随渠道不同；这些差异不能变成长期业务分叉。配置共享与共存方式留给后续规格，不在本阶段设计模块或接口。

# 价格与商业承诺

此前将价格绑定于“基础状态”“手动恢复入口”等功能等级的理由撤回。所有价格候选都必须包含合格的自动挂载核心体验。

- 中国区 AutoMounter 基础价格 ¥68，自动挂载和恢复在基础功能中；额外专业设置 ¥28。这是直接类别参考，不是 automnt 的最优定价证明。
- 建议首版以 US$9.99 为美元市场测试起点，中国区以 ¥68 附近的可用价格点验证；均为 ASSUMPTION / 定价建议，不是换算等价、售价授权或正式承诺。SMB 范围较窄，未证明优于成熟竞品，不建议预先按 US$14.99/19.99 溢价销售；这些仍可用于后续价格测试。
- Apple US$99 年费及 Small Business 获批后的 15% 抽成已核实；税费、退款、本人资格、实际区域净收入和支持成本未知。[研究](research.md)提供明确标注假设的成本情景，不将覆盖年费当作开发回本。
- 买断范围、后续大版本与支持承诺须在销售前明确。免费 CLI 不削减既有自动挂载能力；开源再分发权利仍保留。

# 范围边界

不扩张协议、平台、云账户或订阅；不把修复 Finder 侧边栏或实现 Windows 式按路径即时连接加入此次发行评估的默认承诺；不要求为界面全面覆盖每个内部维护操作而延迟核心价值验证。

# 推荐所依赖的假设

- 商店可允许可持续的后台自动挂载体验，以及必要的网络、凭据和卷宗权限。
- 共同能力可一起维护，发行差异不会逼出两套长期分叉。
- CLI 与 GUI 共存时能避免冲突并向用户提供明确控制。
- 有用户愿意为商店自动挂载产品付款，收入能够覆盖约定支持；问题存在不等于商业需求已验证。
