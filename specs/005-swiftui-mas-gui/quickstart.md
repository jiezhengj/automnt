# 核心独立流程

1. 仅安装 GUI；启动真实 SwiftUI 主界面，由程序定位固定目录并检查合法访问，首次/恢复不要求用户选内部目录；真实授权机制须先通过 T083 论证，再按 T084 接入，不执行 CLI 导入/检查向导，不提供普通用户密码录入、验证或删除。复用系统 SMB 认证/已保存凭据，当前 CLI NetFS 传 nil user/password；sandbox/helper 能否复用仍未验证。主界面打开、挂载变化和重新激活时发现本地当前已挂载 SMB，按服务器分组显示已管理与可添加；逐行“添加”立即持久化，不使用选择 toggle 和“添加所选”。零结果给出 Finder“连接服务器”指引，工具栏手动入口要求完整 `smb://host/share`。验证缺 URL、空共享、重复规范化身份不能添加。随后明确启用后台。
2. 从应用显示的任务路径完成真实文件读写（写操作在获准测试目录），观察健康状态与实际路径。第一次完成后正常恢复不要求 Finder/CLI 手动连接。
3. 关闭窗口与 ⌘Q；确认 GUI/菜单退出，自动化仍启用。由用户重新登录/重启、执行可控网络断开与恢复，确认系统唤醒 helper、真实文件访问恢复，helper 随后退出，无第二评估器/定时轮询。
4. 记录触发到达/无事件角落；不据成功样本承诺任意路径访问即时连接。权限撤销、密码错误、共享不存在、服务器不可达、路径冲突、超时分别显示相应原因，无后台认证窗/竞争无限重试。
5. 验证系统已保存 SMB 凭据在 GUI 退出及重新登录后能由 sandbox helper 复用；当前未验证。必要的外部挂载路径授权与内部配置管理分开核查；固定配置目录访问不代替外部挂载权限，不新增应用密码管理兜底。未开启 GUI 时 helper 仍应运行。自定义路径、标准路径、碰撞路径实际核对，不能只看 API 返回成功。

恢复测试先定义观察窗口与连续三次的步骤，由维护者目视或提供脱敏录屏，记录桌面有无授权/认证提示、人工连接/重试次数并关联事件/真实文件访问时间线。NoUI 或无提示日志不证明无可见提示；缺目视证据则零提示门槛未验证，不降低 SC-001。另验证恢复失败通知：前台请求系统授权后退出 GUI，helper 实际投递；允许/拒绝/系统抑制分别记录，核对每轮一条、同卷同会话两条上限及健康弹出静默；拒绝时不反复索权，下次打开仍有失败状态和立即重试入口，入队日志不当作显示证明。
