# 配置与视觉交互

原生 SwiftUI 主窗口宽窗左侧平铺服务器名与“已管理 N / 可添加 N / 异常”摘要，不展开共享或放操作按钮；右侧显示选中服务器名、“自动挂载此服务器的共享”开关与独立后果说明，下方紧凑已管理/可添加共享组，无固定第三列。共享行仅名称、状态、Finder/修复/添加主动作；URL、路径、索引、编辑和移除按需 sheet。工具栏保留 fullURL 完整 SMB 地址入口，Finder 引导为次级空状态。窄窗按服务器→共享→详情使用系统导航，返回/刷新/添加保持选择、焦点及滚动，以多主机多卷复验。打开、卷变化和重新激活刷新；每行添加立即校验并持久化成员，无多选向导。授权并成功读取确认无目标时的真实空态提供次级 Finder 指引，工具栏提供完整 SMB URL 入口；待授权/读失败不能进入此空态。已有 CLI 配置自动呈现，程序定位/准备固定目录并复用合法访问，不要求内部路径识别、目录选择或导入检查；已有共享仓库/CAS 与协调基础，免目录选择访问机制和真实共存闭环仍待证明。默认系统 SMB 认证，无独立密码管理，沙盒/helper 复用未验证。所有真实目标来自探测或明确输入。优先采用系统语义字体、间距、SF Symbols、原生表单与系统材料；每个状态有文字与图标，不能仅靠颜色。

目标管理：服务器顺序、共享启用、任务路径、编辑/保存/取消、自动恢复、整体自动化启停。详情包含最近观测时间与简洁错误原因，诊断在次级入口。相关地址/路径编辑 Draft 在保存前不改变后台；服务器排序直接拖放即时保存，名称行内确认；缺 SMB URL、共享名、有效挂载位置或身份冲突不能保存。编辑开始捕获原目标身份、baseRevision 与 savedBaseline，提交使用该 revision；服务器地址修改以同一 CAS 事务迁移主机/共享身份和引用并保留顺序，目标移除或变化不盲写。成功更新 revision/保存基线后关闭，或保留编辑且 dirty=false；后续取消不重复询问，失败/冲突保留输入并引导审阅/重读。系统字段标签、输入与说明层级清楚，非活动窗口激活后可正常编辑。真实关闭窗口/⌘Q 入口检查所有活跃 Draft 并提供保存、放弃、取消；保存失败/冲突保留输入并取消退出，成功或放弃后完成实际退出，已保存内容不再提示。当前 quit delegate 的 request/finish 尚未接入，拟由 T088 修复；不能用预览确认替代实际退出保护。自动化继续。

忙碌只限制冲突动作，其余编辑与导航保持响应；取消不声称撤销系统已经完成的挂载。健康、离线、授权不足、失败、会话抑制、后台停用分别有下一步。不新增面向任意路径的卸载能力。

# 菜单栏

默认不插入 MenuBarExtra，核心自动化独立于 GUI。用户单独启用后，按服务器顺序分组、每个共享提供独立子菜单，显示该共享状态及查看详情、挂载、弹出、在 Finder 中打开；动作绑定稳定目标身份并在执行前核对 revision/实际状态，禁用条件、重名及辅助功能按体验契约“菜单目标与登录信息”。列表后按顺序独立提供打开 Automnt、设置…、隐藏菜单栏图标、关闭自动挂载、退出 Automnt；不以当前主窗口选择隐式决定目标。

菜单栏启用不自动注册登录 UI。Settings 另提供“登录时显示菜单栏”，默认 false，仅在菜单栏开启时可选；用户明确开启后通过 SMAppService.mainApp 注册主应用登录项，关闭时注销该项。登录启动只显示菜单，不展开主窗口；普通打开仍打开主窗口，须 T033 验证系统登录启动身份与 SwiftUI 场景行为。主应用登录项与负责有界评估的 helper LaunchAgent 分别管理，登录 UI 不执行评估、不注册第二评估服务。菜单栏关闭时注销 UI 登录项并关闭其偏好，不影响 helper 自动化；用户撤销登录项不自动重新注册。注册失败/待批准显示实际状态，不冒充已启用。本机 macOS 27 SDK SMAppService.h 已确认 mainApp API 存在，实际签名注册/启动仍待 T016/T033 验证。⌘Q 结束 GUI/菜单，自动化继续，menuBarEnabled 偏好保留，下次打开/用户同意的登录 UI 恢复。MenuBarExtra 不运行第二评估循环，状态读取仅在 UI 有需要时进行。

快捷卸载不 force；繁忙报告失败，成功后同会话抑制，网络上下文/登录变化或快捷挂载解除。快捷挂载是有界异常兜底，不暗示每次任务都需点击。

# 诊断与支持

无遥测、广告、第三方分析；诊断默认本机，用户预览脱敏后主动导出，不上传。原始 SMB 用户名、地址、路径、密码、书签/凭据 reference 不进入导出和截图。2026-10-19 维护者确认日志政策：本机日志保留 7 天且单文件上限 5 MB，超限自动滚动清理；设置/诊断提供“清除日志”入口；诊断导出只包含用户预览的脱敏内容，不改变日志；不上传、不增加未批准的数据收集。产品实现（按时间/大小清理与清除按钮）记为 T103，未实现前不宣称已完成清理行为。

支持材料使用现有公开项目托管，准备中英文 support/privacy 稳定页面、Issues 指引及开源许可证。最终可达 URL 可用正式版本固定文件链接，内置同内容便于离线阅读；不能用未发布工作区路径作为商店链接。公开 Issues 提醒不要附敏感内容；不捏造邮箱、法律联系人和 Apple 身份，不承诺终身更新。页面发布属于执行阶段外部动作，遵循已获授权范围，本 Plan 不发布。

# 发行候选与账号边界

共同营销版本来自根版本声明；GUI App Store 更新，CLI 保留免费预编译 GitHub 更新。US$1.99 美元基准买断、完整功能、无订阅/内购/外部激活。源码、自行编译与免费 CLI 说明按提交时政策核对，提供事实准确的替代措辞；不在名称/副标题/截图放不适当价格宣传，不把开源当成商店下载免费或“成本价”的证明。

账号无关交付必须包括：各 target 的最小 entitlements 及实际签名嵌入核对、按实际 API/依赖和提交时官方政策审计并嵌入的 PrivacyInfo.xcprivacy（含 required-reason API 合法理由）、本机构建及可执行签名检查、真实核心/共存/升级证据、视觉交互复验、最终图标与真实脱敏截图、九语商店文案、隐私申报候选、支持/隐私有效 URL、许可与源码编译说明、审核复现材料、版本说明、最低系统 API 审计及证据。无较低系统实测保留 macOS 27；不要求为未知设备编兼容分支。

审核说明不能捏造公共 SMB 环境/账号；准备真实可用的复现方案和必要测试服务器安全边界。若审核必须外部可访问环境，落实实际资源及维护者授权，不能当代理必然能免费提供的条件或偷偷留成额外最后阻塞。

账号最后依赖：付费团队证书/profile、正式签名身份、App Store Connect 实体和价格/隐私登记、实际渠道升级授权测试、上传、提交、审核反馈。免费本机测试不代表这些已完成。免费能力不能完成的额外 entitlement/provisioning 需具体记录原因，不笼统归因账号。只有其他产品/资源工作均通过，才能报告唯一外部前置为付费账号；Apple 审核结果不保证。

# 全产品交互补充

侧栏分已管理与未管理发现服务器；已管理优先级直接拖放和键盘等价移动，即时 CAS 保存并可撤销，首个共享添加后服务器追加末尾。无排序 sheet/草稿/保存按钮；写失败恢复持久顺序，撤销并发冲突不覆盖，选择/焦点/滚动保持。首可达策略、本轮评估服务器、界面选择和已存在挂载分别显示。
