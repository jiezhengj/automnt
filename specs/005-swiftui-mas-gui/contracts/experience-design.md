主窗口采用左右两区：左侧平铺服务器列表，行内仅名称与“已管理 N / 可添加 N / 异常”摘要，不展开共享、不放动作按钮；右侧显示选中服务器名称、“自动挂载此服务器的共享”开关、附近独立后果说明和紧凑“已管理 / 可添加”组。共享行仅名称、状态、一个主动作，已管理项为“在 Finder 中打开”或对应修复，可添加项为“添加”。URL、路径、观测、索引、编辑与移除进入按需 sheet；无固定第三列。工具栏保留完整 SMB URL（fullURL）入口，Finder 引导置于次级空状态；未挂载已管理项继续可见。已管理服务器在原列表直接拖放排序，放下即原子保存，支持键盘/VoiceOver 等价操作及核对 revision 的撤销；不另建排序表单或排序草稿。可添加但尚未管理的服务器独立分组，不参与排序；首共享添加后新服务器追加末尾。过滤搜索时禁用排序，避免插入位置含义不清。保存失败回到真实已保存顺序，冲突重读并提示，不覆盖其他入口更改。在途评估用开始时快照，新顺序只影响后续评估，不立即切换或卸载现有共享。顺序说明为“按此顺序检查服务器，选择首个可达的服务器。该服务器的某个共享挂载失败时，不会因此改用后面的服务器。”同一服务器下列出多个共享，各共享详情提供“启用此共享文件夹”，只控制该共享 enabled，关闭不弹出已挂载卷；服务器详情的“自动挂载此服务器的共享”只控制 HostConfig.enabled，独立辅助说明“关闭后，不再自动挂载此服务器的共享；已经挂载的卷宗仍可使用。”全局开关在 Settings 编辑，主窗口显示后台真实状态与修复入口；首次已添加但未启用时允许“开启自动挂载”明确引导动作，不置常驻全局停用开关。顶部提供完整一轮“立即尝试自动挂载”和独立“刷新状态”，单共享操作不改变服务器策略。查看对象、本轮选择及现有挂载分别显示，全局/服务器/共享故障按作用域去重。

主屏在打开、当前挂载卷变化及窗口重新激活时刷新本机已挂载 SMB 共享；发现范围不包含全网络服务器或服务器未挂载共享的穷举。先按规范化服务器身份合并，再逐共享身份去重：已管理服务器上新发现的未管理共享仍须显示可添加行，不能因主机已经管理就排除整台主机。已管理共享即使离线或已弹出仍保留。刷新只重读配置/后台/挂载观测，不改配置、不执行评估、不抢焦点、不覆盖草稿或重置滚动。代码目前将 managed host 的 addableShares 清空并排除 knownHosts，正式生命周期 volume/activate 观察尚未接入；拟由 T086/T089 修复，不把已有 getmntinfo 本机发现或单行添加写成全无。

每个可添加行提供“添加”，点击后立即校验并原子保存该共享为管理成员，成功转为已管理；无多选、待选列表或集中提交。保存失败保留候选与就近错误及重试入口，不把成员开关当作添加。完整 SMB URL 必须来自实际系统发现或用户明确输入，非空共享名和标准挂载位置可由合法地址推导并允许确认修改；缺字段、无效 URL、规范化重复身份及同服务器路径冲突拒绝落盘；跨服务器备用目标可复用约定位置，运行时仍核对身份和占用，不能声称一定同时可用，不能以当前卷名推造缺失地址。保存前重读配置 revision，冲突不覆盖他人更改。匹配已有服务器时复用其身份、参数与顺序，不重复新建主机；新服务器追加到顺序末尾，后续可调整。

没有可添加共享时以次级空状态指引用户通过 Finder“连接服务器…”连接 SMB 共享，再返回 Automnt 自动刷新；已有管理项仍显示。工具栏“输入 SMB 地址…”始终可达，打开单目标原生表单，要求完整 `smb://host/share`、共享名称及有效挂载位置，不引入服务器探测向导、共享多选或八步首次设置。目录权限仅在目标操作确实需要时说明并通过已验证机制请求；内部配置目录由程序定位和准备，首次或权限修复不要求选择目录。机制未验证时显示真实能力限制，不用普通 Alert 假装已取得系统权限。必要授权或校验失败保留草稿并定位字段；不得静默保存不完整目标。

认证默认由 macOS 系统 SMB 连接与系统已保存凭据处理。应用不提供独立用户名/密码录入、验证、更新或删除入口；认证失败指引在 Finder 重新连接并按系统提示处理。不同签名身份、沙盒应用与 helper 能否实际复用系统已保存认证尚未验证，须真实挂载实测，设计 demo 不能证明其可用。原型仍覆盖同服务器两个共享、第二服务器与顺序调整、逐行保存失败、局部停用及全局停用差异。

设置的“帮助”分组提供“查看诊断信息…”“使用帮助”“支持与隐私”“开源许可”：“支持与隐私”打开离线可滚动正文，说明本机配置、钥匙串、目录权限、服务器连接与用户控制的诊断导出，提供中文/English 正文选择及正式支持和隐私政策链接；其他界面语言明确说明正文语言。链接打开失败保留离线正文并给出复制地址/重试，未知正式地址不得假造为可用；候选正文与未定项见 design/support-privacy.md。标准应用菜单“关于 Automnt”与帮助菜单提供可达入口，关于仅展示版本、开源与支持/许可链接，设置复用同一内容，不建立重复控制中心。诊断先展示脱敏预览，再由用户选择导出位置，取消不写文件；帮助显示自动挂载条件、常见失败修复与退出后后台继续的说明；许可显示随应用交付的完整 MIT License 与适用第三方声明，不依赖联网。四项内容支持滚动、键盘关闭和返回原设置，预览中的说明不冒充已采集诊断或正式许可正文。

设置使用原生 SwiftUI Settings 独立窗口，SettingsLink 与 ⌘, 打开同一窗口，不替换主窗口详情；关闭设置返回原主窗口选中项。开关即时保存，写入失败显示错误并恢复已保存值；设置本身无延迟保存 Draft。主窗口地址/路径关联添加与编辑表单的未保存 Draft 保持自身关闭与 ⌘Q 保护；行“添加”成功后不产生待保存草稿。HTML 仅以独立模拟设置对话窗口表达关系，不作为材料/动效/焦点合规证据。窄窗口按服务器→共享→详情采用系统导航，提供原生返回；返回恢复服务器选择、共享身份和各列表滚动。宽窄切换复用 selectedServer/viewState，不新增固定第三列，不通过截掉关键按钮适配宽度。添加成功后焦点跟随同一共享进入已管理组，不切服务器或滚回顶部；失败保留原行及焦点。多主机多卷与长名称样本须覆盖上述过程。布局原型注明各窗口尺寸、工具栏、状态文字、控件位置、空白与滚动策略；具体尺寸由 T058 原型与 T028 真机共同确认。正常页面不把“连接”设为每日必做的主动作，不能用 UI 健康代替实际挂载证据。

逐页阅读顺序、完整辅助名称、焦点恢复及错误播报按 [辅助功能设计](../design/accessibility.md) 执行；系统默认控件无需重复覆盖名称，额外标签应解决目标或状态歧义。后台意图与实际服务状态必须分别呈现，预览提供 data-model 合成矩阵的九种审阅场景；待批准、停止失败和无法确认时提供各自下一步，不以开启偏好代替运行结论。

# 菜单目标与目标编辑

可选菜单按已保存服务器顺序分组，每个共享依配置顺序提供独立子菜单，名称和当前状态明确对应该共享。菜单动作绑定稳定服务器/共享身份，不依赖主窗口选中项，也不对所有共享执行。子菜单包含“查看详情”“在 Finder 中打开”“挂载”“弹出”：Finder 只在实际位置已核对时可用；挂载须配置和授权可用、目标未挂载且无在途操作；弹出须已核对目标挂载且无在途操作。全局自动挂载或目标 enabled 关闭不禁止用户显式手动挂载，缺授权时引导打开详情修复。执行前重读配置 revision 和实际状态，目标已移除或变更时拒绝过期动作并引导查看最新详情。无配置显示添加入口。

同名共享以服务器名称区分；长名称可以在菜单视觉截断，但辅助功能读出完整服务器、共享名称与状态，详情保留完整值。菜单支持滚动、键盘导航，普通弹出直接执行并明确目标，无例行确认；核对目标、繁忙失败与结果在原目标处反馈，绝不强制弹出健康繁忙卷。全局项按“打开 Automnt”“设置…”“隐藏菜单栏图标”“关闭自动挂载”“退出 Automnt”的顺序放在目标列表后的独立分组。T033/T036 覆盖多个服务器和共享、重名、无配置、目标更新/移除、忙碌与停用组合。

现有共享的“编辑…”在开始编辑时捕获稳定目标身份、baseRevision 与 savedBaseline，包含该共享的完整 SMB 地址、共享名称和挂载位置；字段标签、输入与辅助说明采用原生表单层级。单共享编辑不暗中改其他共享地址；服务器地址/端口整体修改进入关联表单并列出受影响共享，同一 CAS 事务迁移规范化服务器身份、共享地址和引用，保留顺序，导航随后跟随新身份，不继续引用旧 host，也不自动合并到已有服务器。位置变化仅在必要时请求对应外部目标许可，不能把内部配置目录选择加回来。提交必须使用编辑开始时的 revision；目标已移除/身份变化或 revision 冲突时保留输入并提供审阅/重新载入，不在提交时获取最新 revision 掩盖并发修改。字段、空地址、重复身份/路径错误就近显示，合法草稿一次保存，不静默部分应用。成功先更新 draft、baseRevision 与 savedBaseline，再关闭编辑；保留编辑时 dirty=false，后续取消、关闭或退出不重复提示。失败/冲突保留草稿。非活动窗口激活后仍能聚焦、输入与保存。仓库 CAS 已有，编辑起始 revision 及服务器身份迁移仍有缺口，拟由 T087 修复；成功后重复保存提示是维护者反馈，尚未复现，不冒充已证实运行缺陷。T031/T036 的历史引用保留，原生复验拟由 T094 汇总。

移除共享只移除自动化管理成员，不删除系统 SMB 凭据；既有挂载的保留后果在确认中明确。设置、详情、空状态和通知摘要均无独立密码管理入口。T014/T031/T036 的认证验证转为系统 SMB 认证及已保存凭据在真实沙盒/helper 中的复用与失败恢复验证，不把历史密码 CRUD 原型当作现行契约。

| 自动挂载 | Settings；automation_enabled，全部目标 | 停止发起新的自动挂载并注销评估服务；已有挂载保留 | 即时保存后停服务；失败展示真实状态和修复入口 |
| 自动恢复 | Settings；auto_mount_recovery，全部目标 | 不再额外响应卷宗变化尝试恢复；登录与网络变化时的自动挂载仍保留 | 即时保存并停旧/启新固定服务；失败按后台契约回退 |
| 自动挂载此服务器的共享 | 服务器详情；HostConfig.enabled | 独立说明：关闭后，此服务器的共享不再自动挂载。已挂载的共享仍可使用。 | 即时保存，写失败恢复原值 |
| 尝试阻止 Spotlight 索引 | 服务器详情；HostConfig.prevent_spotlight_index，该服务器全部共享 | 后续不再尝试；不删除既有标记，不承诺逆转索引状态 | 即时保存，写失败恢复原值；revision冲突保留意图并要求重新核对，不改其他服务器 |
| 启用此共享文件夹 | 共享详情；SMBShareConfig.enabled | 仅该共享不再参与后续自动挂载；已有挂载保留 | 即时保存，写失败恢复原值 |

“自动恢复”的辅助说明为“共享意外断开后，额外响应卷宗变化尝试恢复。关闭后，仍在登录或网络变化时自动挂载。”不保证每次断开都有系统事件；用户主动弹出后的会话抑制保持不变。关闭自动挂载时，自动恢复控件禁用并保留已保存值；重新开启后恢复该偏好，不隐式改成 true。T033 落地四层独立控制，T036 验证组合与失败回退。

菜单“关闭自动挂载”是明确的可逆动作，立即保存同一 automation_enabled，再依后台契约停服务，无二次确认；邻近说明已挂载共享保留。提交中禁用重复点击，失败不显示已关闭，展示真实配置/服务状态与修复入口。菜单动作不修改自动恢复、服务器或共享 enabled。主窗口的配置表单只读全局状态，菜单显式停用与失败修复入口遵循同一保存契约。

# 首次设置与日常交互

首次打开即进入同一主屏，展示已管理与当前本机已挂载的可添加 SMB 共享；通过行“添加”立即保存，零发现结果采用 Finder 连接指引与次级完整 URL 表单。首次启用后台时说明关闭窗口或退出 GUI 后自动挂载继续，并提供独立停用入口。真实首次挂载、文件可用和后台运行仍须分别核对，保存配置不等于挂载或服务已成功。权限只在对应操作需要时解释和请求；拒绝可返回修改或安全退出，不使用无说明的一串权限弹窗。

已有合法 CLI 配置须在 GUI 自动呈现；程序定位固定真实用户目录并复用有效访问能力，不执行 CLI 导入/检查或内部目录选择。目录访问、原子保存、owner/generation 与操作锁保护唯一活动配置和后台所有权。读取失败保留原因与过期只读快照，不创建平行配置、不发起新挂载或静默接管既有服务。已有固定路径解析、仓库 CAS、访问状态保护与 owner 协调基础，不可写成全无；新的无目录选择访问机制及真实跨身份共存闭环仍未验证，demo 只说明预期。

所有输入只来自真实系统发现/用户输入；未保存草稿不改变活动配置。取消明确放弃当前未保存草稿，保存冲突保留输入并提供重读/重新应用，不静默覆盖；成功按 FR-026 关闭编辑或重设已保存基线。凭据不进入配置、持久 UI 草稿、日志、原型截图或证据。删除目标先说明仅移除自动化配置、是否保留当前挂载，不能暗中执行强制卸载。批量删除若不在首版范围，不制作假入口。

每个可取消异步动作明确取消的是等待还是尚未执行动作；取消后显示核对后的结果，不承诺撤销系统已完成的挂载。忙碌只禁冲突操作，导航和不冲突编辑继续可用。⌘Q/关闭窗口须从真实应用退出入口检查所有活跃 Draft，提供保存、放弃、取消；保存失败/冲突留在编辑，取消退出保持应用，保存成功或放弃后真实完成退出且不重复询问。当前 quit delegate 未接 request/finish，拟由 T088 修复，不能把预览提示当实际退出保护。GUI 退出后已启用后台继续。独立停用不卸载已有健康共享。

# 状态、修复与通知

| 状态 | 用户可见解释 | 下一步与主动作 |
| --- | --- | --- |
| 未配置 | 尚未管理共享；可添加行来自本机已挂载 SMB | 有候选时逐行添加；工具栏完整 SMB URL 可达，次级空态说明 Finder 连接 |
| 待授权 | 具体说明必要目录或后台许可缺失；系统 SMB 认证另给连接指引 | 前台完成对应系统授权，认证问题在 Finder 处理，保留其他配置 |
| 评估中 | 正在检查/挂载及可取消范围 | 不重复提交，允许导航 |
| 健康 | 当前共享已可用、最近观测时间 | 在 Finder 打开 |
| 离线 | 当前服务器不可达 | 自动等待系统事件，可查看地址；不优先索要密码 |
| 失败 | 区分凭据、共享拒绝、路径冲突、超时或其他原因 | 对应修复入口，必要时立即重试 |
| 会话抑制 | 用户已弹出，本次会话不自动重新挂载 | 用户动作“挂载”；解除该目标抑制属于内部语义，不直接作界面文案 |
| 后台停用 | 新自动挂载已停止，现有健康挂载保留 | 日常打开设置，在“自动挂载”中开启；首次添加完成但尚未启用时，主窗口提供一次明确“开启自动挂载”引导，不设置常驻全局开关 |

状态具备文字、图标与辅助功能说明；不可仅靠颜色。授权故障不能显示为离线，约定/实际路径不符不能显示健康。T058 原型覆盖全部状态及修复返回路径，并与结构化核心结果对照。

GUI 原生 UserNotifications；CLI 现有 osascript 适配独立，合并/限额/脱敏由核心共用。默认点击 GUI 通知打开失败摘要并读取最新状态，已恢复时明确当前结果，不依据旧通知直接执行挂载；无需在通知载荷携带目标地址。GUI 前台时只更新应用内失败状态，不额外展示应用内横幅或系统横幅，不请求声音；后台或 GUI 退出时按限额投递系统通知。投递路径须核对前台状态，避免 helper 与窗口各自提醒。失败事件仍按核心合并/计数规则记录，不因前台抑制展示而在切后台时补发旧提醒；T016 验证跨身份前台状态判断及投递行为，无法达成时先修订设计，不临场增加重复提醒。通知默认只提供查看入口，不增加未经验证的后台重试按钮。拒绝、专注模式或系统关闭通知时，保留失败和下次打开修复入口，不反复索权。GUI 退出后的通知身份/投递及点击启动须实际验证。

正常后台成功挂载、恢复和健康弹出无成功通知或应用自定义音效。失败提醒仅请求系统默认通知声音，不另行播放音频。应用设置提供“通知声音”开关，默认开启，辅助说明“关闭后，仍会收到通知。”；偏好按 data-model.md NotificationPreferences 写入同一获授权目录内 gui-notification-preferences.plist，适用于负责投递 GUI 身份通知的后台路径，GUI 退出后同样有效；存取错误及未验证的持久目录授权按该契约处理，不能用内存开关代替验收。关闭后新通知 sound 为 nil，不撤回已经送达的声音，不影响通知内容、授权、失败限额或自动挂载；开启时可请求默认声音，但是否响仍由系统声音/通知/专注模式决定，不绕过系统控制、不以声音作为唯一信息。GUI 偏好不隐式改写 CLI 的渠道设置。通知本地化不暴露共享名、地址或路径。

# 通知授权与索引防护入口

通知首次请求仅由前台设置窗口“通知”分组中的“允许通知…”显式动作发起，共享添加、后台 helper 和启动过程不自动弹窗。未决定时说明通知只用于未能自动挂载的共享；允许后显示“通知已允许”，声音偏好保持独立。拒绝后显示持续说明“通知未允许。你仍可在 Automnt 查看挂载问题。”并提供“打开通知设置…”；不重复调用授权请求。系统关闭通知或专注模式只显示核对到的系统设置，不推断横幅必达；返回设置窗口重新读取授权，不改变失败计数或补发旧事件。授权请求失败保留原因与重试入口。辅助功能读取授权状态后再读取动作，系统弹窗返回焦点落在发起按钮。

共同 prevent_spotlight_index 意图在服务器详情“索引防护”分组通过“尝试阻止 Spotlight 索引”呈现，映射该稳定服务器身份的 HostConfig.prevent_spotlight_index；独立辅助说明“应用于此服务器的所有共享文件夹。尝试减少 Spotlight 索引产生的磁盘和网络活动，但可能限制 Spotlight 对这些共享内容的搜索。不会删除已有索引；系统限制可能使防护无法生效。”不新增全局字段，不覆盖其他服务器的值；不同服务器可保持不同值，新添加服务器默认值遵循现有共同配置规则。关闭不删除既有标记，不承诺逆转系统索引状态。逐共享详情独立显示索引防护结果：未启用、等待挂载后检查、已完成可验证的防护步骤、已尝试但无法确认系统索引状态、受限或失败。完成步骤也不等于系统已经停止索引；每个结果旁给实际可核对的范围、原因与下一步“查看诊断信息…”，不索取管理员权限。挂载健康与防护结果分别显示，防护受限不改变健康共享的 Finder/弹出可用性。当前CLI及商店渠道真实效果按共同核心契约实证，能力差异不能静默隐去。

# 视觉、动效与可访问性

T059 的原生基线为 macOS 27 SwiftUI 系统组件：NavigationSplitView/List、Form/Section/LabeledContent、toolbar、Settings、sheet/alert、ProgressView、系统选择器与 SF Symbols。积极按场景组合，不用网页样式决定产品字号、字重、色值、圆角、焦点或动效；采用默认/语义字体与 .primary/.secondary 等层级，尊重系统强调色和辅助功能。操作标签只写明确动作，后果另用辅助说明；全页面文案依项目 AGENTS.md 长期原则和 design/localization.md 修订。材料服从系统组件职责，不给所有内容添加玻璃。真实原生预览与应用复验是合规依据，HTML 和网页 PNG 只作流程/构图参考。正式图标方案与界面一起审阅，禁止占位图成为最终资产。

动效表逐项定义触发、表达目的、时长/缓动、可打断行为与减少动态效果替代；覆盖列表/详情切换、行添加与手动添加表单、保存反馈、状态变化与等待。系统组件明确记录“采用系统默认”及实际复验，不强行指定覆盖系统的数值；仅经审阅的自定义动效才给具体数值，不留“自然协调”空项。无装饰性无限动画；等待用系统指示器并提供文字，减少动态效果时保持结果可理解。声音政策见前节。

键盘顺序、默认/取消动作、Esc、返回、保存快捷键与 VoiceOver 朗读在原型逐页注明；Return 不意外触发删除或卸载。状态刷新不抢焦点、不重置滚动和草稿。截图验证布局，录屏验证等待、取消、保存、异常修复、退出及动效；最终使用真实原生应用复验，原型不能证明沙盒能力。

# 界面文字与多语言布局

界面采用系统语义字体和组件间距，以信息层级及阅读顺序组织布局。标题、状态、主要动作、字段与辅助说明分别呈现；错误原因和下一步持续可见，不依赖悬停。布局允许译文自然换行，不用缩小字号或固定行高解决长文案。

| 场景 | 布局策略 | 验证重点 |
| --- | --- | --- |
| 主窗口列表与详情 | 原生分栏；窄窗列表→详情并保留返回和选中项；内容纵向滚动 | 服务器/共享长名称可访问完整值，状态不会遮挡名称，导航与焦点顺序稳定 |
| 详情操作 | 主要动作、修复和移除按职责分组，纵向布局或原生自适应重排，禁止要求全部按钮恒在一行 | 各语完整动作标签可读；正常/窄窗及较大文字下没有压缩、截断或动作不可达 |
| 设置与表单 | Form/Section；标签及说明自适应高度，长说明换行，必要时标签和值上下排列；窗口允许滚动 | 长开关标签、错误和说明均完整显示；禁用原因靠近相关控件 |
| 单目标添加/编辑 sheet 与确认 alert | 输入内容纵向滚动，字段与说明自然换行；默认/取消及危险动作采用系统布局 | 长译文和错误不遮挡保存；失败保留输入，成功关闭或重设基线，较小可用高度仍可完成操作 |
| 菜单与工具栏 | 系统菜单随标签布局；工具栏采用原生溢出策略；主要功能有明确可达入口 | 不固定中文宽度；长译文不丢失关键动作，图标按钮有本地化可访问名称 |
| 地址、名称及计数 | 长路径可换行或选择复制；仅必要时截断并提供完整值及可访问朗读；完整句子使用格式参数和复数资源 | 长用户输入、数字单位、N=0/1/2/较大值、中日韩与拉丁文本混排 |

# 本地化交付

首发 GUI/通知/菜单/辅助功能及商店说明覆盖英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语（en、zh-Hans、zh-Hant、ja、ko、de、fr、es、pt-BR）。CLI 可保持中英文，不新增业务规则分叉。语言默认跟随系统；用户可在系统应用语言设置切换，应用提供指引，不另维护与系统冲突的语言偏好。

品牌不翻译；术语表按语言固定 SMB、共享、挂载、恢复、弹出/卸载、停用及权限解释。字符串采用可复数化资源、完整句式和格式参数，不拼接句子；日期/数字使用用户 locale。原始用户共享名保持原文，不翻译。通知失败数量需复数验证。

每种语言记录译文覆盖、关键权限/删除/卸载/修复与价格承诺的质量复核、长文本布局、VoiceOver 与复数检查；机器翻译生成不等于复核通过。伪本地化提前发现布局缺陷。若无法获得可靠复核，在 T060/T036 明确语言发布缺口，解决或经维护者明确批准调整首发范围并同步 spec/plan/tasks/商店说明；不能默默回退双语后宣称完整。

支持/隐私完整页面首发中英文，其他语言界面明确链接所用语言；商店和支持说明不承诺九语客服。审核说明和开发资料可保持中英文。各已声明语言的商店元数据与最终截图方案在 T045/T048 完整核对。

# 首次设置访问与真实系统许可（方案 A）

首次仍进入同一原生主窗口，内容区采用 SwiftUI `ContentUnavailableView`，标题“开始使用 Automnt” / “Get Started with Automnt”，解释需要读取和保存自身设置，已有共享会自动显示。首次及取消后“继续…” / “Continue…”触发定位与访问检查；失败时说明实际原因并提供重新检查/恢复访问。仅在 T083 证明适用的真实系统许可机制后，才接入允许/拒绝及其准确动作文案；机制未验证时不得展示暗示可以授权的假流程。有效访问能力直接读取，静默显示既有目标；拒绝/取消返回原按钮焦点，不显示零目标统计、不写业务配置、不新挂载或接管。

正常首次、主窗口、设置、菜单、CLI 共用和权限恢复不显示内部配置路径，不设置配置位置字段，不提供选择/更改/导入入口，不要求寻找 Application Support、选择文件夹或手工建目录。程序核对真实用户路径并在合法权限内准备所需目录；显式诊断调查可按需展示路径且遵守脱敏规则。外部挂载目标与用户主动诊断导出各自的合法资源选择不是内部配置目录授权。

`NSOpenPanel` 的预定位、Allow Access prompt、固定目录/父目录筛选、临时父 scope 和子书签属于历史实现，不是当前规范。user-selected read/write entitlement 以用户选择扩展访问，书签保存已有合法授权；它们无法证明任意固定外部目录具有无 picker 的通用 Allow/Deny 授权。禁止把普通应用 alert、后台运行批准、全磁盘访问或 GUI 私有书签等同所需的 sandbox 读写/原子替换/锁能力。当前 Apple 文档尚未证明完整访问架构；T083 先论证各身份与操作，T084 才接入统一访问入口。涉及签名、CLI 协议、IPC、App Group 成员或发行渠道的影响须先记录，不擅自迁移或建立第二配置。

| 当前情况 | 用户看到与可执行动作 | 数据行为 |
| --- | --- | --- |
| 首次未授权/取消 | 用途说明、继续/重新检查；真实许可允许或拒绝，取消恢复焦点 | 无目录选择、虚假零目标、业务写入、新挂载或后台接管 |
| 固定目录身份不符（wrongDirectory） | 设置访问异常及恢复入口，不要求用户重选目录 | 不接受替代副本、不保存错误绑定、不回退容器 |
| 固定目录不存在 | 程序在合法权限内准备；无法准备时给出真实原因及重试 | 目录 0700；首次有效添加才生成 0600 配置，不假定父 scope 已获准 |
| 访问记录需更新（bookmarkStale） | 说明需检查设置访问 | 仅实际访问仍合法时安全更新；否则通过已验证机制恢复 |
| 权限失效（permissionRevoked） | 说明无法读取设置及下一步 | 保留原目标，恢复后重读最新 revision，不自行扩大权限 |
| 已授权但读/解析失败（readFailed） | 未能读取设置及原因、重新读取/修复 | 不进入空态、不覆盖原文件；旧快照标过期只读，禁新挂载/接管 |
| 成功读取既有目标（ready） | 自动进入左右主界面，保持稳定身份及真实数量 | 同一 CLI 活动配置，CAS 保存 |
| 成功确认无配置/目标（authorizedUnconfigured） | 真实空态、工具栏完整 SMB URL、次级 Finder 指引 | 有效单行添加即时保存；不存在不等于读取失败 |

配置访问、后台运行许可及 SMB 系统认证分别说明和修复。前台授权不证明 helper 权限；独立 helper 在 GUI 退出、登录、重启和稳定签名升级后的读写、锁、SMB 与凭据复用由任务 T093 验收。文案表达实际影响，不向用户展示 owner、书签或后台协议；系统真实许可采用系统行为，不增授权音效。九语、长译文、窄窗、较大文字、键盘/VoiceOver 和焦点由任务 T094 复验。历史 T079–T082 和[历史实施证据](../../../release/evidence/option-a-authorization.md)仅保留当时范围，不把面板操作列为当前产品的通过条件。
