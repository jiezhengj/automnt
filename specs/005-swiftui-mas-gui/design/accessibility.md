# 本轮主界面与添加焦点

宽窗先读取左侧平铺服务器名及已管理/可添加数量、异常摘要，再读取工具栏完整 SMB URL 入口与右侧选中服务器标题、“自动挂载此服务器的共享”和独立后果说明，随后已管理组、每项完整名称/状态/Finder或修复主动作、可添加组及每行“添加”。左侧不展开共享或包含动作，详情 sheet 承载 URL/路径/索引/编辑/移除，关闭恢复发起共享焦点。窄窗按服务器→共享→详情使用原生返回，恢复选中服务器和共享身份、各列表滚动；宽窄切换、刷新及添加均不重置这些状态。只添加当前行，成功后该行移入已管理组，焦点跟随同一共享，宣告保存结果；失败保留原行并读原因，不以多选确认代替。刷新不抢焦点。已有 CLI 配置自动呈现，不增加导入检查焦点步骤；共享配置与 CAS 已有本地实现，跨身份权限与真实 owner 闭环未验证，发现合并/生命周期/无选择/窄导航待修复。

完整 SMB URL sheet 读取标题、地址字段、系统认证说明、就近错误、取消/添加。错误聚焦地址；保存失败保留输入；成功关闭或重置 draft/baseRevision/dirty。系统认证由 Finder/macOS 完成，应用无用户名/密码管理页。Spotlight 说明需完整读出减少索引活动、搜索受限与实际效果未验证，不自动删除已有索引。

# 全产品当前焦点与等价操作

已管理与未管理发现服务器按组朗读。管理组拖放排序提供键盘等价上移/下移，即时保存并宣告位置；保持身份焦点，边界动作禁用后选择同对象可用动作。撤销可达且并发冲突宣告，不恢复旧列表覆盖新修改；没有排序草稿或 Esc 放弃顺序。选中对象/评估所选/既有挂载分别可读，状态刷新和进度不抢焦点。

普通弹出直接执行、失败回目标并读原因；仅移除配置有安全确认。详情先状态和位置，再自动安排/编辑/移除/弹出及索引。Settings 增共享重试参数，实际后台/通知授权与声音独立朗读；系统语言/外观、原生 About/Help、离线支持/许可/脱敏预览全键盘可达。名称行内确认与相关地址/路径成组提交各保留错误焦点。
