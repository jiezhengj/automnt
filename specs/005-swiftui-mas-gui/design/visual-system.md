# 本轮流程与证据范围

主窗口宽窗采用左右两区：左侧平铺服务器列表，仅服务器名与“已管理 N / 可添加 N / 异常”摘要；右侧显示选中服务器标题、独立自动挂载开关及附近后果说明，下面为紧凑“已管理 / 可添加”共享组。左侧不展开共享或放动作按钮，无固定第三列；共享行只呈现名称、状态和 Finder/修复/添加主动作，URL、路径、索引、编辑、移除按需进入 sheet。工具栏提供 fullURL 完整 SMB 地址入口，Finder 为次级空状态指导。窄窗服务器→共享→详情使用系统返回，选择、焦点和滚动在返回/刷新/添加后保持，多主机多卷样本用于当前审阅。可添加行提供“添加”，一次添加一个共享并立即保存，不进入八步向导或多选草稿。已管理但当前未挂载的配置仍显示其真实状态。已有 CLI 配置应自动出现在同一管理界面，不要求用户检查或导入；共享配置、访问状态和 CAS 已有本地实现，权限机制、跨身份访问与单 owner 真实闭环仍未验证，演示不证明共同管理通过。

# 字体、颜色与材料

正文与标签采用组件默认文本样式。需要标题层级时用系统 .headline、.title 等语义字体，不自行规定 26px/14px 或统一加粗。为每种使用情境明确层级，不给所有文本统一覆盖字体。

用户提到的注释色对应次要信息层级，SwiftUI 可用 foregroundStyle(.secondary)；尺寸依上下文采用默认正文或 .footnote/.caption 等系统语义样式，不固定一个灰色。开关的作用和后果是可读说明，不降成极小文字。重要失败/限制不能只用 tertiary 或颜色表达。

主文字使用 .primary，辅助说明使用 .secondary；强调与选中由系统 tint/accent 处理，尊重用户系统强调色。错误与破坏性语义使用系统 role/提示和文字；健康状态不必自造绿色胶囊。背景、separator、材料、焦点、控件尺寸与禁用状态由系统组件管理。浅深色、减少透明度、增加对比度均在目标系统验证。

Liquid Glass 的使用依系统导航/控件默认行为，不给内容表单、每行数据或文字背景随意加玻璃。macOS 27 特有更新须查证对应官方资料与 SDK，不能把 WWDC25 的描述直接当 27 的逐条要求。

# 用户文案与信息层级

按钮命名说动作，辅助说明说结果。例如服务器开关名“自动挂载此服务器的共享”，关闭后的说明“已经挂载的共享文件夹仍可使用。”菜单动作“关闭自动挂载”配独立说明，不写“停用自动挂载（保留挂载）”。“弹出”沿用熟悉的系统动作名称，内部的普通卸载/强制卸载区别留在工程契约。“挂载”不用“快捷”修饰。

状态说明给用户下一步：离线先说明服务器暂时无法连接；认证失败引导先在 Finder 连接并完成系统认证；权限或能力受限给实际原因与诊断入口；已弹出解释什么时候会再次自动挂载。用户不需要知道锁、代次、内核快照或服务所有权来操作。

完整文案语境及多语言安排见 localization.md。模拟触发器与工程验收说明须在原型审阅层区分，不进入产品文案资源。

# 动效、等待与声音

| 触发 | 目的 | 时长与缓动 | 中断 / 减少动态效果 |
| --- | --- | --- | --- |
| 导航、sheet、菜单、按钮反馈 | 系统层级与即时操作反馈 | 采用系统默认；不覆盖固定时长 | 系统中断与辅助功能行为；真实系统验证 |
| 共享状态更新 | 表达当前结果，不打断阅读 | 默认立即更新，无自定义过渡 | 新结果替代旧结果，不重置焦点/滚动位置 |
| 单行添加与编辑 | 保持顺序与当前输入 | 系统默认布局即时更新，不加自定义位移 | 保留非敏感输入；减少动态效果不增加运动 |
| 等待 | 表示未完成 | ProgressView 系统默认，不约定自制节奏 | 可停止等待；减少动态效果采用系统行为并保留文字 |
| 保存/恢复 | 说明结果 | 原位置持续状态，无 3.8 秒自动消失作为唯一反馈 | VoiceOver 去重宣告，不抢焦点 |

设计结论：采用原生组件默认交互动效，不采用额外装饰动画或自定义音效。下表是本轮明确决策，改变必须先同步设计契约和任务。

| 场景 | 动画/动效结论与理由 | 声音结论与理由 |
| --- | --- | --- |
| 启动、首次空状态、图标 | 静态；不加启动片头、呼吸或装饰循环，尽快呈现内容 | 无；应用按需配置，不打断用户 |
| 列表/详情、窄窗口返回、菜单、sheet/alert、设置与选择器 | 系统组件默认；表达导航与层级，不重复添加手写过渡 | 不主动播放；控件或辅助功能由系统产生的反馈不由应用接管 |
| 单行添加、编辑、保存、冲突、取消与退出 | 直接更新内容；不加滑动、抖动或成功庆祝，避免干扰输入与焦点 | 无；结果由持续文字与必要系统对话框说明 |
| 自动/手动挂载、探测、验证与取消等待 | ProgressView 与文字，结束移除指示；不可伪造百分比或完成动效 | 无；进度与取消不应打断文件任务 |
| 健康、恢复、离线、权限、失败、已弹出、关闭自动挂载 | 立即更新就地状态；不闪烁、弹跳或反复动画；失败用文字与操作 | 无应用内声音；正常挂载、恢复和健康弹出也不发成功通知 |
| 失败系统通知 | 系统通知呈现，由系统控制；应用不加第二套横幅动效 | 采用系统默认通知声音，可关闭；避免漏看失败，又保留安静使用方式 |
| 诊断预览/导出、移除配置 | 系统对话框默认与就地结果，不加完成特效 | 无；必要确认提供文字，不用音效表达破坏性 |

减少动态效果：系统控件遵循系统设置，所有等待与结果均有文字；应用不额外补偿旋转、缩放、滑动。复验普通/减少动态模式、快速切换与新结果覆盖、关闭 sheet/取消等待、焦点与 VoiceOver 结果宣告，不能以“系统默认”免除实际检查。网页静态进度线不代表原生进度样式。

声音闭环：设置增加 Toggle“通知声音”，默认开启，辅助说明“关闭后，仍会收到通知。”，独立于系统通知权限。持久化的 GUI 通知渠道偏好由实际后台投递者读取，退出/重新打开 GUI 后有效；关闭时后续通知不请求声音，开启请求系统默认声音，系统仍可静音或抑制。前台不重复提醒，声音不增加通知次数。系统默认声音无需生成资产；无自定义音效播放路径、预览播放按钮或音量滑块。

资产评估结论：不采用自定义音效，因为系统失败通知已覆盖注意力提示，成功与日常操作需要安静，不引入额外声音语义和资产。若未来审阅改为采用，必须先由 Agent 生成音频与可再生成源，交付格式/许可记录和听审样本，并为生成、集成、可关闭偏好、后台读取与持久化、静音/重复播放/系统控制验证设置明确 Task；维护者无需准备素材。当前无需为不采用的效果生成占位资产。
