**当前规范（2026-10-13；保留方案 A 架构，撤回目录选择例外）**：程序决定并准备固定目录，GUI/CLI 使用真实用户的唯一活动配置及单后台 owner。首次、设置、CLI 共用和恢复均不让用户选择、寻找或手工创建内部目录；之前 NSOpenPanel/父目录选择例外撤回。仅在真实系统授权需要时允许/拒绝，普通应用 alert 不产生沙盒文件权限；免目录选择机制尚未证实，不承诺通用 Allow/Deny API。失败不创建平行配置、不显示零目标、不新挂载或接管，已有快照只读。历史 290 项测试、签名与中文首次窗口不证明当前权限、独立 helper 生命周期、MAS 或九语验收。本轮仅文档，最新规格覆盖旧实现与历史评审。

# 产品目标与共同能力

核心价值仍是后台自动挂载与恢复，让依赖 SMB 文件的任务尽可能在执行前获得约定路径；不保证任意时刻访问成功，不声称修复 Finder 侧边栏或按路径访问即时连接。既有本地实施和门禁为历史范围；本轮先审计并修订文档，未对外发布。

CLI 与 GUI 共用目标配置、身份与校验、服务器选择、有限尝试、恢复与主动弹出识别、后台协调及结构化结果。界面交互可以不同：CLI 会话批量提交，GUI 完整的单步操作即时提交；二者使用相同配置校验和并发保护。渠道安装、升级、系统许可及界面偏好分别适配，不形成两套业务规则。

当前 CLI 按保存顺序选择首个启用且可达的服务器，只处理所选服务器的启用共享；共享失败不会触发服务器切换。并行自动挂载多台 NAS 不属于本次新增能力。列表中查看对象、本轮选择对象及仍有现存挂载的对象分别表示，不能混成“当前服务器”。

# 首次使用与已有用户

首次和日常打开进入同一主窗口，无向导。未具备所需访问时使用原生 ContentUnavailableView“开始使用 Automnt”/“Get Started with Automnt”，解释读取/保存自身设置及自动显示已有共享。首次及拒绝后“继续…”/“Continue…”，实际访问错误恢复“允许访问…”/“Allow Access…”；仅按已验证机制在确有需要时调用真实系统授权，不保证每次点击有弹窗。有效访问静默复用，合法 CLI 目标自动呈现，无导入检查。拒绝/取消不写业务配置、不新挂载、不接管；读失败保留只读快照，不显示真实空态或建立平行配置。免目录选择权限与独立 helper 持久访问尚未闭环，demo 不证明可用。

主窗口、设置、菜单与首次/恢复支持无内部完整路径、配置位置字段、选择/更改/导入或查找/创建内部目录指导。程序决定并准备固定位置，不把目标或父目录交给用户选择；唯一业务配置仍为真实账户的 `~/Library/Application Support/automnt/automnt.plist`，以 `getpwuid(getuid())` 解析账户目录，不采用沙盒 HOME。目录 `0700`、原子文件 `0600`、CAS revision、稳定锁 inode 与 owner generation 保持既有契约；不建立 App Group 平行业务存储。显式诊断可按需显示路径。准备目录须先具备真实访问权限，首次有效添加才写业务配置，普通 alert 不提供权限。无目录选择机制待当前 Apple 资料与真实签名身份验证；若需改变位置、签名、CLI 协议或发行渠道，先记录影响，不能擅自迁移或建立第二活动配置。

已具备所需真实访问且成功确认无配置，但存在本机已挂载 SMB 时，展示可添加服务器和共享；单行添加立即校验保存。没有可添加目标时简述用途，工具栏“添加共享…”仍可达，Finder 连接指引为次级说明。不进行全网络扫描、不列举服务器未挂载共享。

添加成功、后台启用、真实文件可用分别反馈。首次保存后尚未启用自动化时，在主窗口给“开启自动挂载”明确动作，解释登录/网络变化后执行、退出 GUI 后继续、关闭自动化不弹出现有卷。只在用户同意后注册后台；已有开启意图继续使用但核对实际许可。必要权限在对应操作时请求；通知许可不混入添加或启动。

# 主窗口与直接操作

左侧分“已管理”和“可添加”。已管理服务器按保存的检查顺序显示，支持原生拖放插入及键盘/VoiceOver 等价移动；未管理发现服务器不参与排序。第一项共享添加到新服务器时，该服务器追加管理顺序末尾。移除最后一项时清理空管理服务器，仍被发现则保留为可添加对象。

行内只名称、已管理/可添加数量与问题摘要，可用简短状态标记表达正在检查/本轮已选择；不增加操作按钮或展开共享。拖动只修改后续评估顺序，不立即切换或卸载挂载；在途评估使用开始时快照。放下即 CAS 持久化，无排序 sheet、排序草稿或保存按钮。失败回到实际已保存顺序；冲突加载真实最新值并提示；成功可撤销，撤销同样核对 revision，不覆盖后续别人更改。

右侧标题区显示名称、独立服务器自动挂载开关及后果说明、服务器设置入口；需要时说明此次为何未选择。右侧已管理/可添加共享行仍仅名称、状态、一个主动作。地址、路径、索引、移除进入详情。服务器名称通过明确重命名原位确认提交，不在逐字输入时写配置。

顶部显示后台真实状态及最近一次结果时间，正在评估时就地显示过程。选择服务器只改变查看对象；后台不自动选择、滚动或重排列表。已挂载事实不因本轮选择改变。未检查的服务器不能显示离线；主动弹出、停用、未选中不计异常。

长列表提供名称搜索和原生键盘定位，搜索不改变保存顺序；过滤时禁用排序以免插入含义不清。打开、挂载变化和重新激活读取发现与状态，不用周期轮询；刷新不抢焦点、不覆盖编辑。添加成功焦点跟随目标进入已管理组，滚动和选择保持；仅身份真正消失才回退。

# 添加与编辑

真实候选信息完整时单行添加；缺字段才打开预填表单补齐，不从卷名猜 URL。手动“添加共享…”首要输入完整无凭据 SMB 地址，从合法地址推导名称和标准挂载位置，可修改推导结果；主动作“添加”。匹配已有服务器时复用参数、身份和顺序。

开关、排序和完整单值确认即时提交；地址/路径等关联字段以草稿一次提交，不能保存逐字无效中间值。表单错误就近显示、保留输入；取消不改变配置。成功保存关闭编辑器，或继续编辑时以已保存值重置 draft/baseRevision/dirty，后续取消不提示已保存修改。编辑开始固定 baseRevision 与目标身份，提交据此 CAS；冲突、失败或目标消失保留草稿，不在提交时取新 revision 绕过冲突，身份改变后不向旧对象再次保存。

共享编辑不暗中修改全部服务器地址；服务器地址/端口的关联修改在服务器表单中明确列出受影响共享、一次校验提交，不自动合并既有服务器。位置修改不迁移当前挂载，说明任务可能需要修改使用路径。

跨服务器备用目标允许配置相同约定路径，同服务器重复身份/位置拒绝；运行时核对实际身份与路径占用，不能同时挤占、静默改位置或把备用路径复用误判全局重复。具体可用性须真实挂载验证。

# 状态、详情与修复

共享使用事实与自动化安排分别处理。详情阅读顺序：当前状态/原因/下一步 → 约定与实际位置 → 地址、观测时间、自动安排 → 编辑、普通弹出、移除 → 索引结果、诊断。健康依据实际身份、路径和健康证据，不能只依据配置或挂载表。

| 情况 | 表现与下一步 |
| --- | --- |
| 健康且位置正确 | 在 Finder 中打开 |
| 正在挂载/恢复 | 系统进度；禁止重复同目标，导航继续 |
| 健康主动弹出 | 已弹出；本网络/登录会话不重挂；显式挂载恢复该目标资格 |
| 此次未选择 | 原因指向本轮所选服务器，不显示失败 |
| 自动挂载关闭且已挂载 | 仍显示可用；安排在详情说明，不暗中弹出 |
| 服务不可达 | 等待有效系统事件；检查网络或主动尝试，不承诺固定恢复时间 |
| 认证问题 | Finder 系统连接指引，返回后核对，不提供密码管理 |
| 实际与约定位置不符 | 位置不符，任务可能无法访问；列出两位置和处理入口 |
| 失效连接 | 区分正在恢复、恢复失败与无法确认；不把未知当死卷 |

全局许可/服务问题只在全局摘要说明；服务器不可达在服务器范围说明；共享拒绝/路径冲突在目标行说明，避免重复相同修复提示。索引防护与健康分别显示，尝试完成不等于系统已停止索引。

完整“立即尝试自动挂载”按已保存配置执行一轮，单共享“挂载/重试”只操作该目标，“刷新状态”不挂载。关闭全局自动化禁用完整自动评估，但用户仍可显式手动操作目标。结果附时间，正常成功无确认或通知。取消明确能取消等待还是尚未执行部分，不声称撤销系统已完成动作。

普通弹出核对真实目标与健康、非强制、繁忙失败不标已弹出；无需例行成功前确认。移除管理需要说明不弹出、不删除远程文件或系统凭据；本次不新增批量删除。后台修复死卷不等同用户弹出。

# 设置与菜单栏

设置分组：自动挂载（意图开关、实际后台状态、恢复偏好及修复）/菜单栏与登录（偏好与实际登录项）/通知（系统授权状态、允许或系统设置入口、独立声音）/高级（共同 retry 参数和既有值）/支持（诊断、帮助、隐私、许可）。不提供误导性的“失败通知”内存开关代替系统授权；通知授权被撤销不反复申请。声音偏好持久化与后台渠道访问须实际验证。

外观和默认语言遵循系统，应用语言按 macOS 设置处理，不新增重复语言/主题选择。全局设置即时保存，写失败回到保存值；服务操作失败保留意图但显示实际差异。自动恢复关闭只改变卷变化恢复，登录/网络评估保留；全局关闭时禁用恢复控件并保留值。

菜单栏默认关闭，登录显示单独选择，后台不依赖二者。原生菜单按保存服务器顺序分组，共享状态及 Finder/挂载/弹出/详情绑定真实身份；过期目标拒绝操作并读新状态。管理操作回主窗口。末尾独立打开主窗口、设置、隐藏菜单栏、关闭自动挂载、退出；不把退出解释成后台停用。

# 通知、诊断、帮助与生命周期

失败沿共同合并/限额；前台只更新界面，后台按确认状态投递，不补发旧失败。正常成功/恢复/健康弹出静默。通知点击读取当前状态，一个问题定位，多个问题摘要可逐项进入，已恢复明确报告；不按旧载荷执行动作，不暴露敏感目标。

诊断脱敏预览后由用户选位置导出，取消不写入；局部入口带问题上下文，全局入口汇总。日志保留/清理策略仍待确定，不伪造实际采集或已批准数值。标准应用 About 与 Help 入口展示版本、开源/许可/支持；离线帮助按用户问题组织，支持/privacy与完整许可离线可读。正式 URL 未落实不展示伪可用链接。

关闭窗口/退出GUI不停止已启用后台，无 dirty 不确认；只保护未提交表单。明确关闭自动挂载停止新动作、保留挂载；停止失败不能显示完全停用。升级保留配置和权限，系统撤销不自愈重开。GUI 商店更新、CLI GitHub 更新分别适配。

具备所需真实访问后，已有 CLI 配置直接呈现；后台接管单独解释并获同意，有界排空旧服务、核对新服务，只一个执行所有者。失败保持真实 stopped/原渠道或待批准状态。GUI不能执行外部CLI来伪装接管，旧版本不协作给具体恢复指引，必要升级/停用不能隐藏。

# 共同演进与尚缺能力

现有应用已有单行添加、完整无凭据 SMB URL、用途说明、访问状态与 CAS，不应描述为完全未实现。确认缺口包括已管理服务器新增发现共享未合并、编辑开始 revision/身份及保存基线不足、实际退出草稿保护未接通、生命周期观察不足、无选择引导及窄导航不足。保存后反复提示为尚未复现的用户反馈，不将全部 save 判为故障；共享编辑与原生 demo 的成功关闭证据不证明服务器编辑或实际退出通过。 CLI 已有 `--mount <smb-url>` / `--eject <smb-url>` 和部分真实 CLI SMB 证据，不能外推 GUI/helper 系统认证、免目录选择访问和独立后台恢复通过。

以后新增能力同时定义共同意图、操作作用域、结构化结果/原因、兼容规则和CLI/GUI呈现。核心不由UI猜状态；GUI不解析终端输出。共同契约与验收见 [core-and-channels.md](../contracts/core-and-channels.md)，完整体验落实见 [experience-design.md](../contracts/experience-design.md)。

# 原型与验收边界

HTML为流程审阅，SwiftUI为隔离原生设计预览；均只虚构内存数据，无真实网络、配置、Keychain、挂载或服务。审阅工具与产品界面分离。历史PNG/评审只证明当时范围，不能当本方案全产品或原生实测证据。真实认证、CLI透明访问/单owner、路径/后台恢复、通知退出后投递、VoiceOver/九语/宽窄窗口均待实际应用验收。

必须覆盖首次四类入口、多服务器多共享、直接排序成功/失败/冲突/撤销、过滤排序限制、添加/后台/可用三结果、全部状态及修复返回、设置/菜单/通知/帮助诊断、关闭退出升级和渠道共存。动效只用系统交互与等待，长译文/较大字/浅深色/减少动态效果/键盘VoiceOver逐界面核对。
