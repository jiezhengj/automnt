# 保守边界与残余限制

卷健康探测运行于有时限子进程，以目录访问的明确 I/O、连接或 stale 错误识别会话失效。权限拒绝、无法启动、探测超时及预算耗尽均为不可确定信号，不据此卸载卷。主机不可达且卷仍在挂载表时只保留修复证据，不执行清理；主机恢复可达后重新检查卷健康，仅明确失效才清理。旧修复证据不覆盖当前健康信号。清理与 NetFS 子进程共享恢复轮剩余预算；进程终止回收可能增加少量尾部时间，实际总体耗时需 T018/T019 校准。

WatchPaths 竞态没有被完全消除。修复方式是增加 StartOnMount、配置推导的各标准挂载目录及 /Volumes 监听，并在交互入口收敛旧服务定义。漏掉事件时恢复推迟至下一次事件、登录或手动入口；无固定最长等待时间，不增加周期轮询。
