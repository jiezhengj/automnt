**Feature**: 挂载丢失自动恢复（Mount Loss Auto-Recovery）

**Artifact**: 挂载恢复行为与接口契约（Mount Recovery Contract）

**Feature ID**: `004-mount-loss-recovery`

**Created**: 2026-10-05

# 1. 恢复触发契约（事件驱动，零周期）

- 服务由以下事件唤醒，执行一次短命的“恢复判定轮”，跑完即退：
  1. 登录（`RunAtLoad` 等价语义）；
  2. 系统网络配置变化（既有触发源）；
  3. **挂载命名空间变化**——分两路：系统级“文件系统挂载时启动作业”键**只在挂载时触发**（覆盖卷回归/恢复成功），挂载目录增删监听（`WatchPaths` 类，官方标注竞态可能漏事件）**覆盖使用者弹出**；弹出侧漏事件的后果 = 该次不唤醒（保守方向），由下一次事件/登录/手动入口兜底。
- 服务定义 **MUST NOT** 包含固定周期启动键（`StartInterval` 类）；程序内 **MUST NOT** 存在等待型常驻循环（FR-009 / Constitution II）。
- 恢复判定的时效口径：**事件唤醒后的当轮评估内**完成，不设钟表时限（clarify Q1 裁决）。
- **自触发防护**: 本程序自身挂载/卸载会再次触发挂载命名空间事件，形成“挂载→唤醒→挂载”的重入环；恢复判定轮 MUST 幂等（已挂载即跳过）并 MUST NOT 因自身动作产生新的恢复尝试，避免自激（对应 SC-003“无挂载-掉载风暴”）。
- 既有 `WatchPaths` 竞态（官方标注可能漏事件）为已知风险：漏事件的后果上限 = 推迟到下一次事件/登录/手动入口，**MUST NOT** 放大为覆盖使用者意图。

# 2. 判别与抑制契约（三重信号，保守方向）

对“配置启用的卷缺失/失效”，按以下序判定：

| # | 信号 | 判定 | 动作 |
|---|---|---|---|
| 1 | 卷仍在挂载表但失效（健康探测失败/会话丢失） | 网络丢失 | 清理死卷（写清理账）→ 纳入恢复 |
| 2 | 卷缺失 + 在清理账中（产品自清） | 产品动作 | 纳入恢复 |
| 3 | 卷缺失 + 修复性弹出证据（缺失前存在会话丢失证据） | 使用者修复动作 | 纳入恢复 |
| 4 | 卷缺失 + 信号 1–3 皆不成立 + **状态可读且 `everHealthyMounted=true`** | 使用者健康弹出 | **会话抑制**：本会话零重挂 |
| 5 | 卷缺失 + **状态可读且 `everHealthyMounted=false`**（全新安装/新加入的启用卷） | 无挂载证据，非弃用 | **不进抑制**；按基线段挂载范围在主机可达时挂载（FR-002④） |
| 6 | 任一信号不可读 / 状态损坏 / schemaVersion 未知 | 未知 | **按 4 处理**（保守方向，US2 AC4）；**MUST NOT** 被当作 5 而自动挂载 |

- 会话抑制解除边界字面：**“网络上下文变化或重新登录（先到者为准）”**（FR-004）。
- **信号 3 的证据通道（尽力而为，非 MUST）**：判据 = 该卷缺失前，本机在**同一会话内**留下过“该 SMB 会话丢失/重连”证据。通道优先级：① 程序自记的会话丢失证据（本特性可在检测到卷失效时自行落盘，**不依赖非公开 API**）；② 系统日志文案（`log show` 类，属非公开 API、存在版本漂移风险，仅作增强）。**通道不可读或证据缺失时 MUST 降级为信号 4（保守抑制）**，不得推断为修复性弹出。因此健康弹出（信号 4）与修复弹出（信号 3）的区分由“缺失前是否存在可读的会话丢失证据”这一可观察条件决定，而非读取使用者意图。
- 判别 MUST 按卷粒度独立成立；本特性 **MUST NOT** 提供任何弹出/卸载功能（维护者裁定的能力边界）。

# 3. 恢复执行契约（有界、幂等、零打扰）

- **前置**：主机可达性探活通过（沿用 TCP 445 非阻塞探活）；卷已挂载则直接跳过（幂等，FR-005）。
- **有界**：单轮恢复沿用既有有界重试窗口（默认 ≤3 次尝试、间隔 1s、总窗口 ≤10s，可随既有重试策略字段配置）；用尽即停并记录 outcome，**MUST NOT** 形成持续后台重试。
- **零凭据交互**：恢复全程 **MUST NOT** 弹出凭据/登录对话框；凭据仅由系统钥匙串静默提供（FR-006）。
- **失败分类**（供恢复尝试记录）：`host-unreachable` / `share-rejected` / `credential-failure`；每卷每轮的失败推进通知判定（见 §4）。

# 4. 兜底契约（通知 + 一键）

- **通知时机**：一轮事件评估结束时，仅存在当轮结束仍未恢复的实际失败→ 发通知；会话抑制（含健康弹出、同路径备用身份及保守跳过）不发失败通知，不消耗通知计数，菜单入口保持可用；**每轮至多一条**，内容合并列出受影响卷（US3 AC3，去重依据恢复尝试记录的轮内序号）。**会话级上限**：同一卷在同一可达会话内至多通知 2 次（首轮一次 + 一次提醒），此后该会话内不再重复通知，避免每次挂载命名空间事件都触发；边界解禁或成功挂载后计数归零。
- **通知字面（纯文本，无操作按钮——既有 `osascript display notification` 通道不支持动作）**：
  - 标题：`automnt：挂载未自动恢复`
  - 副标题（沿用既有通知助手的 subtitle 参数）：`自动恢复未完成`
  - 正文模板：`以下共享未能自动恢复：<卷列表>。请在 automnt 配置管理菜单中选择“立即重新挂载”。`（指引到菜单入口，不要求使用者敲命令）
  - 全文走既有双语机制（`zh`/`en`），英文标题 `automnt: Mounts Not Automatically Restored`。
- **菜单入口字面**：`automnt --config` 主菜单新增动作项 `立即重新挂载`（置于全局管理动作区，位于 `保存并退出` 之前）；执行语义 = **开关为 `true` 时**触发一轮完整恢复判定并保持菜单可用；**开关为 `false` 时**执行语义回退为“基线段挂载评估”（按配置挂载缺失的启用卷，恢复判定与会话抑制不执行），菜单同样保持可用——即关闭开关不剥夺使用者手动恢复的能力，但手动入口不因此启用自动恢复逻辑。
- 通知为纯文本指引，不承诺携带可点击动作；**菜单入口 MUST 始终可用**，是唯一的一键恢复路径。

# 5. 配置开关契约

- 字段：`auto_mount_recovery`（布尔；缺省视为 `true`），语义见 data-model §5。
- `true`（默认）：§1–§4 全部生效；服务定义事件源 = 登录 + 网络配置变化 + 挂载命名空间事件。
- `false`：恢复判定与会话抑制**不执行**；**服务定义事件源回滚**为登录 + 网络配置变化两种（严格回落至现状触发集），菜单 `立即重新挂载` 入口**仍可用**（手动动作不属于自动恢复）。
- **切换生效路径与时机**：开关切换只发生在交互式 `--config` 路径；由该路径同步重生成并重载服务定义（`true`=三事件源，`false`=两事件源），重载失败走既有安装自愈路径并给出明确错误。**守护进程自身绝不得重生成/重载服务定义**（`registerOrUpdateLaunchAgent` 会先 `bootout` 再 `bootstrap` 当前正在运行的作业，自终止）。下一次事件评估即按新触发集运行。
- **唯一起源规则**：事件源集合 MUST 由唯一生成器依 `auto_mount_recovery` 派生，所有注册、重生成与升级收敛路径（含安装自愈）MUST 得到与配置一致的集合；`false` 时任何路径 MUST NOT 写回三类事件源。既有安装（两事件源）在开关为 `true` 时 MUST 通过交互式入口收敛为三事件源，不得仅靠改二进制完成；**该收敛 MUST 发生在 `--config` 读入配置后、进入菜单之前**（此时开关值取自磁盘，不涉及未保存的内存副本），**MUST NOT 挂在 `--config` 退出路径上**——否则与“未保存即 Esc 退出时服务定义不变”直接冲突。
- **既有自愈的已存在风险**：`main()` 无参数运行时经 `InstallState.healIfNeeded() → registerOrUpdateLaunchAgent()` 同样会 `bootout`+`bootstrap`，且 `isServicePlistValid` 只校验 Label/args/`StartInterval`、不会发现事件源过时——实现必须先封堵该绕过路径（守护运行态护栏或令其短路），否则“守护进程内绝不重载”与事件源一致性均不成立。
- **“守护进程运行态”判定谓词（MUST 可判定）**：实现须提供一个显式谓词，建议以“由 launchd 启动”为准（如进程无控制终端 `isatty` 为假、且父进程为 launchd / 或经环境标记由服务定义注入 `ProgramArguments` 之外的判别项），并在自测中以注入方式断言该谓词为真时不执行重生成/重载。禁止以“无参数即守护进程”作为唯一判据——`--config` 之外的既有无参数交互路径同样无参数。
