# 场景 1：初始化向导高阶选单全流程验证

## 验证步骤

1. 执行向导重置：
   ```bash
   ./automnt --init --reset
   ```
2. 观察候选主机界面：
   - 验证候选主机列表与动作项（手动添加、跳过、完成）是否融合成统一单选列表；
   - 按下键盘下方向键（或 `j`）与上方向键（或 `k`），验证高亮指针 `❯` 平滑上下移动，屏幕无整屏抖动；
   - 移动光标至目标主机并按 `Enter` 键，验证直接进入该主机配置，全过程无需输入任何选项数字编号。
3. 验证主机别名受限单行输入：
   - 输入测试字符后按退格键，验证字符即时被擦除；
   - 直接敲击 `Enter` 键，验证系统自动继承主机名作为默认别名并进入共享选择。
4. 验证从属共享空格多选：
   - 验证界面以复选框展示所有从属共享；
   - 按下 `Space` 键，验证目标项在 `[x]` 与 `[ ]` 之间自由翻转；
   - 按下 `a` 键，验证在全选与清空之间切换；
   - 勾选目标共享后按 `Enter` 键，验证批量完成提交。
5. 验证向导末尾单选：
   - 更新策略与守护服务确认均以高阶单选列表呈现，直接方向键移动并按 `Enter` 确认。

# 场景 2：日常管理主菜单单选与从属管理流转验证

## 验证步骤

1. 启动日常管理：
   ```bash
   ./automnt --config
   ```
2. 验证主菜单单选直达：
   - 主菜单顶部为已配置主机顺位列表，下方紧随新增主机、调整顺位、删除主机等操作项；
   - 方向键移动光标至顺位 1 主机并按下 `Enter` 键；
   - 验证系统直达该主机的从属管理二级菜单，无需敲击 `1-1` 类似代号。
3. 验证二级菜单单选操作：
   - 二级菜单呈现“追加共享”、“批量删除共享”、“批量切换启用状态”、“返回上一级”；
   - 选择追加共享并回车，验证再次通过复选框勾选新共享并批量提交；
   - 选择“返回上一级”并回车，验证平稳返回主菜单。

# 场景 3：主机顺位“两步单选”原子重排验证

## 验证步骤

1. 在日常管理主菜单中，光标移动至“调整主机顺位”并按 `Enter`；
2. 第一步（选择待移动主机）：
   - 系统展示所有已配置主机列表；
   - 方向键选择目标主机并按 `Enter` 选定；
3. 第二步（选择目标放置顺位）：
   - 系统展示所有目标顺位槽位列表（如 `顺位 1`、`顺位 2` 等）；
   - 方向键选定目标槽位并按 `Enter` 确认；
4. 验证结果：
   - 控制台输出成功反馈，主菜单即时以重排后的最新顺位渲染呈现；
   - 验证全过程彻底淘汰了历史输入 `u`/`d` 移动字符的落后模式。

# 场景 4：破坏性操作“空格单选确认防呆”阻尼验证

## 验证步骤

1. 在日常管理主菜单中，光标移动至“删除主机”并按 `Enter`；
2. 在待删主机列表中选定某台主机并按 `Enter`；
3. 观察破坏性操作确认弹窗：
   - 验证默认焦点停留在安全项，单选状态明确为 `❯ (o) 取消并返回`，破坏项为 `( ) 确认删除`；
4. 测试回车防呆取消：
   - 直接敲击 `Enter` 键，验证操作立即安全取消，主机未被删除；
5. 测试移动焦点未按空格防呆取消：
   - 再次进入删除确认，按向下方向键将焦点指针移至确认项 `❯ ( ) 确认删除`；
   - 不按 Space 键，直接敲击 `Enter` 键；
   - 验证系统依然坚决判定为安全取消并返回，主机未被删除；
6. 测试显式翻转后确认删除：
   - 再次进入删除确认，将焦点移至确认项并按下 `Space` 键；
   - 验证单选状态明确翻转为 `❯ (o) 确认删除`，安全项变为 `( ) 取消并返回`；
   - 此时敲击 `Enter` 键，验证系统才正式在内存工作副本中执行删除。

# 场景 5：长列表固定滚动视口与 50ms 独立 Esc 验证

## 验证步骤

1. 长列表视口自动化验证：
   - 运行 `./automnt --self-test`，确认报告包含 `PASS rolling selection viewport scrolls while keeping cursor visible` 且最终失败数为 0；
   - 该自测通过程序内部生成的 20 项选单和内存按键序列驱动光标滚动，断言滚动后的可视范围为 `1..<13`，无需创建或挂载测试共享，也不改写用户配置。
2. 当前环境现场交互验证：
   - 使用 `./automnt --config`，进入一台当前真实发现且已配置的主机菜单；
   - 用现有挂载共享检查单选菜单能正常显示，再按 Esc 返回上级菜单；
   - 若当前挂载共享数未超过终端视口容量，本步骤只记录真实现场菜单可用性，不将其作为长列表滚动覆盖证据；超过容量时再通过真实共享向下滚动并观察 `▲` / `▼` 指示符与光标可见性。
3. 50ms 独立 Esc 判定验证：
   - 在交互终端的单选选单、多选复选框或文本输入界面中单独按一次 `Esc`，测量按键至取消输出的时间；
   - 确认取消响应不等待后续按键；并通过 `./automnt --self-test` 中 `PASS readKey probes a lone Esc byte with the 50 ms timeout` 核实独立 Esc 使用 50ms 有界探测。

## 环境与证据说明

长列表行为由程序生成的 20 项内存选单进行确定性验证；真实终端现场步骤使用系统当前发现的真实挂载，不要求伪造业务配置或额外挂载超过 15 个共享。若当前真实列表未超过视口容量，应如实记录这一限制，并以长列表自动化自测作为超过视口容量时的滚动证据。

# 场景 6：管道降级与自动化自测试套件全绿验证

## 验证步骤

1. 非交互管道降级验证：
   - 为取消、策略探测和保存三个分支分别创建全新的临时用户目录；`CFFIXED_USER_HOME` 只作用于当前命令及其子进程。运行前记录活动配置 `automnt.plist` 的 SHA-256，运行后必须完全相同。
   - 取消分支：先运行一次仅送入空行，确认非 TTY 流式选单流式输出真实发现的候选主机与编号动作项；空行解释为取消，退出码为 `1`，且临时目录中不生成 `Library/Application Support/automnt/automnt.plist`。本次输出中的编号可能随真实候选主机数量变化，必须从输出动态提取，不得假定跳过选项固定为第 4 项。
     ```bash
     active_config="$HOME/Library/Application Support/automnt/automnt.plist"
     before_sha="$(shasum -a 256 "$active_config" | awk '{print $1}')"

     cancel_home="$(mktemp -d)"
     cancel_output="$(printf '\n' | env CFFIXED_USER_HOME="$cancel_home" AUTOMNT_LANG=en ./automnt --init)"
     cancel_status=$?
     skip_index="$(printf '%s\n' "$cancel_output" | sed -nE 's/^[[:space:]]*\[([0-9]+)\] Skip host configuration.*/\1/p' | head -n 1)"
     test "$cancel_status" -eq 1
     test -n "$skip_index"
     test ! -e "$cancel_home/Library/Application Support/automnt/automnt.plist"
     ```
   - 策略探测分支：输入同一真实菜单中的“跳过主机配置”编号后，在更新策略菜单按空行取消；同样要求退出码为 `1` 且不生成配置。根据策略菜单的真实输出动态提取 `off` 编号，供成功分支复用。
     ```bash
     probe_home="$(mktemp -d)"
     probe_output="$(printf '%s\n\n' "$skip_index" | env CFFIXED_USER_HOME="$probe_home" AUTOMNT_LANG=en ./automnt --init)"
     probe_status=$?
     off_index="$(printf '%s\n' "$probe_output" | sed -nE 's/^[[:space:]]*\[([0-9]+)\] off([[:space:]]|$).*/\1/p' | head -n 1)"
     test "$probe_status" -eq 1
     test -n "$off_index"
     test ! -e "$probe_home/Library/Application Support/automnt/automnt.plist"
     ```
   - 成功保存分支：使用上面动态提取的“跳过主机配置”和 `off` 策略编号，确认向导结束、退出码为 `0`，并在隔离目录生成配置。该配置必须由 `automnt --init` 自己完成探测与保存，禁止手工预写或伪造 `automnt.plist`。
     ```bash
     save_home="$(mktemp -d)"
     save_output="$(printf '%s\n%s\n' "$skip_index" "$off_index" | env CFFIXED_USER_HOME="$save_home" AUTOMNT_LANG=en ./automnt --init)"
     save_status=$?
     printf '%s\n' "$save_output"
     test "$save_status" -eq 0
     test -e "$save_home/Library/Application Support/automnt/automnt.plist"
     ```
   - 三个隔离命令完成后，重新读取真实活动配置摘要并确认与 `before_sha` 相同。非 TTY 脚本验证的是管道降级与真实探测/保存，不得描述为物理终端按键验证；物理 TTY 场景应另以伪终端或真实终端记录，不能用本段冒充。
