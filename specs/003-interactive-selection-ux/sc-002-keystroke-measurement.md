# 测量口径（预先声明）

- **按键计数**：一次物理按键计 1。方向键计 1（其转义序列三字节按一次按键计）；字符输入逐字符计 1；回车、空格各计 1。
- **驱动方式**：阶段驱动按键回放——每一步先等待真实程序出现对应提示，再发送该步按键；任务完成以程序输出的完成标记为准，未见完成标记的运行判为证据失败并重测。
- **同任务、同状态**：新旧版本执行完全相同的任务；配置状态由**程序自身的向导**生成（基线 3.1.0 向导生成 v3.1.0 配置，确保两个版本都能读取），再以文件副本方式分发到两个版本的隔离 `CFFIXED_USER_HOME` 目录。
- **新旧版本**：旧版为 git `e8dba58`（v3.1.0）源码以相同优化参数编译；新版为当前 3.2.0 工作区构建。基线副本旁放置占位 `automnt.swift` 以跳过程序的自搬迁自删逻辑，测量行为不受影响；所有测量进程均在隔离 home 内运行。
- **实测/推导标注**：表中按键总数均为**实测**（实际发送给真实程序的按键序列）；降幅百分比为按实测数计算的派生值。

# 环境事实

- macOS 27.2（Apple silicon arm64），Swift 6.4 编译。
- 真实发现候选主机 2 台（内核 SMB 挂载表动态发现）。
- 本环境 DNS 将 `*.example.invalid` 解析并接受 445 连接，因此手动录入主机的“离线确认”分支不出现；生成脚本对此自适应，两个版本同环境同事实。
- 旧版 3.1.0 拒绝加载 `version` 高于自身的配置（“配置文件版本 v3.2.0 高于当前程序 v3.1.0”），故状态必须由旧版向导生成；两版可读。
- 附带事实（已独立验证）：3.2.0 打开 v3.1.0 配置会原地升舱迁移（version 3.1.0→3.2.0，字节重写）；v3.2.0 配置下的管理会话按 Esc 放弃为字节级不变，工作副本暂存契约成立。

# 结论（如实报告）

1. SC-002 要求的“记录每项任务实际按键总数，并报告各流程任务数量及均值”义务由本报告完成；表中数字全部为实测。
2. 修订前的旧指标含“较旧版平均减少 50% 以上”的预设目标；维护者于 2026-10-04 裁决该预设百分比缺乏实测依据、予以修订移除（见 SC-002 现行表述：以实测记录为依据，不设预设百分比目标）。实测降幅随口径而变：主代表任务口径 50.0%，全矩阵口径 37.9%，单任务区间 −16.7% ～ 75.0%；本报告数据保留为体验基线。
3. 结构性规律：共享多选与默认/首选项目标优势显著（默认全选后回车直达、进入首选主机 1 键对 2 键；向导共享提交经 US1/AC3 对齐后为单次回车直达提交）；小列表顺位调整与非首选项目标持平或略差——新版把全局动作排在主机列表之后，触达动作项需要方向键导航，旧版代号输入在深菜单上按键更少。这是“消灭代号输入”范式（FR-001）与按键总数之间的固有权衡。
4. 维护者已裁决（2026-10-04）：SC-002 修订为以实测记录为依据的衡量条款，移除预设百分比目标；实现层义务（消灭代号输入、提供高阶选单、同任务同状态实测与报告）均已达成，无待决项。
