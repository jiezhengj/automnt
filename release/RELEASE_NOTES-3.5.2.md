# Automnt 3.5.2：局域网外回退与界面误报修正

本次为修复版本（PATCH）。GitHub Release 只提供 CLI 预编译二进制，不含 GUI App。

## CLI 可感知的变化

- 离开 NAS 所在局域网后，首选主机在探测阶段以连接类失败结束时，同一轮内自动改挂配置里下一条可达主机的同一共享，不再把整轮留到下一次触发或人工处理；共享被拒、凭据失败仍如实上报，不回退。
- 可达性探测改为端到端 SMB 判定：Bonjour 实例名先经 DNS-SD 解析 SRV 目标，连接后完成一次 SMB2 `NEGOTIATE` 往返才判可达。本机 fake-ip 代理和只接受 TCP 的端口不再被误判为 SMB 服务器；局域网名在局域网外解析失败立即判不可达，不会拖满整轮预算。
- 监听 `/Library/Preferences/SystemConfiguration` 变化：Tailscale 上线、网络切换等系统网络状态变化会启动恢复轮；共享已由配置内另一条主机承载时，后台不再把它当作挂载点冲突。
- 配置格式、命令与默认策略保持兼容，无需迁移。

## 同仓库源码修复（不随本 Release 分发）

- GUI：同一共享由配置内另一条主机（例如局域网外的 Tailscale 地址）承载时，按「可用」显示，不再把可用共享误报成「位置被占用」并计入侧栏待处理；详情只提供「在 Finder 中打开」，弹出与挂载仍留给实际承载挂载的那条主机条目。真正第三方卷占用配置路径时仍报「位置被占用」。
- GUI 源码按 MIT 开源，可自行编译；本 Release 不提供构建好的 App。

## 下载

- `automnt`：预编译 CLI（macOS 27 / Apple silicon），下载后先 `chmod +x`。
- `automnt-3.5.2.sha256`：CLI 的 SHA-256 校验值。

## 升级

替换旧 `automnt` 即可，配置与后台状态沿用；如之前由 App 持有后台所有权，CLI 后台自动挂载仍按既有 owner 规则处理。
