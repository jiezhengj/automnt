# Automnt 3.6.0：菜单栏「快捷挂载」

本次为功能版本（MINOR）。GitHub Release 只提供 CLI 预编译二进制，不含 GUI App。

## 变化

- 菜单栏图标的菜单里，原来的「立即检查 / Check Now」改为「快捷挂载 / Quick Mount」，动作与开机时一致：按配置把每个共享文件夹过一遍，缺的挂上；不再只是查看状态。主窗口「服务器」菜单同名同行为，⌘R 保留，两处调用同一套逻辑。
- 全部成功时不出现任何新增文案；有失败时在菜单内给出摘要，并用「未挂载的共享文件夹」子菜单逐项列出名称与原因（需要重新登录 / 位置被占用 / 服务器拒绝 / 未完成 / 其他），点进去打开对应共享详情。摘要保留到下一次执行或配置变更。
- 不可用时改为动作前说明：尚未添加共享、自动挂载未开启、后台挂载未就绪、正忙四种情况直接置灰，并紧邻一行给出原因与下一步，不再点下去才解释。
- 失败判定只统计「尝试过且仍不可用」的目标。服务器不可达、本轮未轮到、被你手动弹出的共享不计入失败，避免误报。

## CLI 可感知的变化

无。命令、参数、配置格式与后台策略保持兼容，升级不需要迁移。

## 同仓库源码修复（不随本 Release 分发）

- GUI 源码按 MIT 开源，可自行编译；本 Release 不提供构建好的 App。本次功能位于 GUI，详见 `specs/006-menubar-quick-mount/CHANGELOG.md`。

## 下载

- `automnt`：预编译 CLI（macOS 27 / Apple silicon），下载后先 `chmod +x`。
- `automnt-3.6.0.sha256`：CLI 的 SHA-256 校验值。

## 升级

替换旧 `automnt` 即可，配置与后台状态沿用。
