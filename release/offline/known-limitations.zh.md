# 后台与权限

- 自动挂载依赖应用后台项目与系统许可。未获许可时，界面显示“已关闭/无法确认”，不会伪装成功。
- 固定配置目录通过精确的 home-relative entitlement 访问；该机制在真实签名 GUI 上已验证读写，但 MAS 审核接受性未验证。
- 独立 helper 的后台挂载（原 T095/T096）：缺陷链已修复——改为在 helper/App 进程内执行挂载（`Sources/AutomntPlatform/MountExecutionService.swift`），helper 就绪判定改为固定 LaunchAgent 定义 + `XPC_SERVICE_NAME` + 已提交 backend-state。2026-10-24 19:00 真实重启后无人工操作两卷自动挂载、观测 healthy。仍不可执行的是真实“注销再登录”轮（会中断会话），且同一 boot 内会话边界不刷新属设计限制；根因与逐轮证据见 `specs/005-swiftui-mas-gui/CHANGELOG.md`。
- 失败通知：采用“helper 记录、常驻 App 投递”。明示限制：App 退出、未设为登录项或通知权限被拒/撤销时，后台失败不会通知；10 分钟过期记录不补发——要后台失败通知，必须在登录时运行并常驻菜单栏图标。端到端已于 2026-10-24 实测（17–22 秒内投递系统横幅）；系统拒绝/paused/过期在真实链路未逐项复验（有单测覆盖）。
- 菜单栏图标是常驻进程的唯一可见入口：登录项启动只显示菜单栏、不打开主窗口。已实测真实重启常驻启动、菜单栏点击、浅深色、九语启动渲染、GUI 内弹出/挂载、VoiceOver 朗读与可访问名称（8 个控件补标签后无名产品控件为 0）。真实“注销再登录”不可执行；动态字体不支持（见下条）；证据见 `specs/005-swiftui-mas-gui/evidence/2026-10-24/`。
- 沙盒无法读取已挂载网络卷内容：GUI/helper 只能核验挂载身份，不能读取卷内文件（App Sandbox 限制）；用户自己的非沙盒应用仍可正常读写（实测 `ls` 正常）。因此本应用不提供“内容已可读”的自证，真实文件可用性需用用户自己的应用验证。
- 手工 `diskutil unmount` 会被记为本会话已弹出，之后同会话不再自动挂载（符合会话抑制设计）；等价模拟已确认边界变化会清除该抑制，但真实重启前处于 suppressed 状态的清除尚未直接观测（T138）。
- 会话边界与会话抑制（2026-10-24 第六轮）：沙盒进程读不到 utmpx，helper 的会话边界以系统启动时刻（`sysctl KERN_BOOTTIME`）为兜底（写作 `<boot>-console-unreadable`），因此只有重启才会进入新会话；同一启动内“退出登录再登录”不会刷新会话边界，该会话内被记为用户弹出的共享会一直不自动挂载，可用界面中的“立即尝试自动挂载”，或对单个共享点“挂载/重试”恢复。重启后边界刷新已用等价模拟与 2026-10-24 19:00 的真实重启验证（两卷自动挂载、observations healthy、边界更新为当前会话）；真实重启前处于 suppressed 状态的清除未直接观测。
- 无应用后台控制时，“弹出”会提示先在设置中完成配置；仍可在 Finder 中弹出，不会强制卸载。

# CLI

- `--mount`/`--eject` 需要可用的后台所有权与 launchd 注册。本机 `--install` 注册失败时，命令会拒绝并可能误报 `requiresRepair`（T101）。
- CLI 3.5.0 不受本轮缺陷 A/B/C 影响（非沙盒、扁平单二进制、不派生 worker、不查询 SMAppService）；但本轮未安装 CLI，且 backend owner=app，CLI 自己的后台自动挂载仍未验证，不得写成已通过。
- CLI 只操作已配置共享，不猜测或模糊匹配其他服务器。
