本构建用于本地与同团队验证，以下限制是产品当前事实，不是待办文案。

# 签名与分发

- 使用免费 Apple Development 签名，不是 Developer ID，未公证；其他 Mac 可能被 Gatekeeper 阻止。不能把它当作面向公众的正式分发。
- App Store 提交、商店定价与审核未执行；相关任务已延后，待维护者后续单独发起付费账号需求。
- 不同设备上的权限连续性与升级连续性未验证。

# 后台与权限

- 自动挂载依赖应用后台项目与系统许可。未获许可时，界面显示“已关闭/无法确认”，不会伪装成功。
- 固定配置目录通过精确的 home-relative entitlement 访问；该机制在真实签名 GUI 上已验证读写，但 MAS 审核接受性未验证。
- 独立 helper 在真实注销/重启后的持久访问未验证（阶段 11 T095）。
- GUI 退出后后台 SMB 挂载与系统 SMB 认证复用未验证（T096）。
- 无应用后台控制时，“弹出”会提示先在设置中完成配置；仍可在 Finder 中弹出，不会强制卸载。

# CLI

- `--mount`/`--eject` 需要可用的后台所有权与 launchd 注册。本机 `--install` 注册失败时，命令会拒绝并可能误报 `requiresRepair`（T101）。
- CLI 只操作已配置共享，不猜测或模糊匹配其他服务器。

# 语言与辅助功能

- 九语资源覆盖与八语真实窗口检查已完成；译文为项目内自审 + 外部辅助尝试（agy 未产出可用结论），未做母语人工认证。
- VoiceOver 实际朗读与系统“较大文字”矩阵未验证（T099）。
- 图标在退出确认面板已显示；Finder/Dock/浅深色/小尺寸的最终目视未记录。

# 配置与日志

- 日志保留/清理政策尚未由维护者决定（T003）；当前不会自动清理。
- 配置由程序生成，未手工写入。测试留下的真实配置可能包含已管理共享；可在应用内移除。
